# 利用现有 Field II 与海信体模数据实现六参数闭环优化

日期：2026-09-07。本文基于当前文件、数据头、读取器、生成代码及引用的“论文解析”对话进行分析。它是实施建议，不代表已经训练模型、找到最佳参数或完成主机闭环实验。

## 1. 核心判断

现有数据足够启动“体模任务驱动的分层闭环优化”，尤其适合后端 Digital Gain、Digital TGC、Dynamic Range 的离线控制与验证。Depth、Frequency、TX Focus 可用已采网格构建有限动作的离线回放环境；完整主机闭环仍需新参数下的真实采集来验证。

推荐路线：数据契约与质量约束 → 无参考指标和少量结构标注 → 后端确定性优化、前端离散搜索 → 搜索生成带置信度的伪标签 → 轻量模型加速 → 实机验证。

“没有 ground truth”需要拆开：目前没有公认的最佳 B-mode 图像、专家质量分数或最优参数标签；但仿真有结构真值，实机有同位置的参数干预与重复测量。可以用这些建立可检验的优化任务。不能把自定义评分的最优解称为真实最佳图像。

### 2.1 未经 Gain/TGC 处理的 envelope：已经找对入口

生成代码先得到 `depth_envelope`，另行调用 `fieldii_apply_gain_tgc()` 生成显示包络，再编码 `/algo_bc0`。因此：

```text
/envelope → 数字 Gain/TGC → 显示窗口与编码 → /algo_bc0
```

本次分别抽查 uniform/cyst/point 一帧，根据 envelope、已存 TGC 曲线、增益和动态范围复算 `/algo_bc0`，最大差均为 1 个 uint16 计数，符合量化差异。当前 `bmode_opt/fieldii_loader.py` 已使用 `/envelope`；不应改用同名 `/algo_bc0`，也不应再给原始 envelope 执行“去 TGC”。

这里“原始”只表示在可控数字 Gain/TGC 之前；envelope 已经历波束合成、包络检测和深度重采样，不是通道 RF。

### 2.2 Depth 在仿真里的含义不完全等于主机采集 Depth

`fieldii_generate_dataset.m` 先按频率、焦点进行最大深度仿真，再调用 `fieldii_crop_depth.m` 裁剪，并重新插值到 1851 行。全部数据头的 `simulation_max_depth_mm=65`。

因此当前仿真适合研究视野覆盖、目标放大比例、显示采样与后端曝光随深度变化；不能据此证明真实主机改变 Depth 后的采集时序、帧率、内部处理和分辨率响应已被模拟。仿真中深度较浅时像素数增加所表现的“更锐利”，也不能直接作为物理分辨率提升。

频率和焦点仍对应生成代码中的独立仿真调用。前端深度策略需要以海信实采为主要证据。

## 3. 两类数据怎么对齐

### 3.1 对齐处理阶段，保留域差异

共同表示采用显示前浮点 dB 图和真实空间坐标：

\[
L_{sim}(x,z)=20\log_{10}\frac{\max(E(x,z),\epsilon)}{E_{ref}},
\qquad L_{real}(x,z)=BC0(x,z)/a+b.
\]

其中海信的比例 a 和偏置 b 来自设备标定约定。当前代码默认 a=877.3 counts/dB，偏置可并入显示参考；这些是项目标定值，不是厂家通用常数。

共同数据项建议：`source, scene_id, session_id, position_id, mode, depth_mm, tx_frequency_mhz, focus_mm, x_mm, z_mm, valid_fov_mask, pre_backend_db, gain_ui, tgc_ui[8], dr_ui, calibration_id, action_support`。

仿真附带结构掩膜；实机附带基准帧、漂移记录、目标 ROI 和重复测量组。仿真 HDF5 的体模引用路径含旧目录 `full_recovery`，加载关联体模时应按 stem 与当前 `phantom` 目录解析，不能盲信旧相对路径。

海信 BC0 根据现有标定文档是可控后端之前的对数域观测，但仍可能含此前内部 DTGC、接收处理等效应。把两者换算到同一 dB 单位，只完成了表示对齐，没有消除物理域差异。不要直接比较两域平均亮度并解释为真实穿透差异。

### 3.2 统一后端执行器

\[
Y=\Phi\!\left(43+\frac{255}{W(DR_{ui})}
\left[L+C(z)+G+\sum_{k=1}^{8}B_k(z)t_k-P\right]\right).
\]

Φ 表示裁剪、量化及经验证的灰阶映射；B 为八滑块的插值基函数；P 为固定参考点。当前近似模型：

- `W(DR_ui)=0.3519*DR_ui+35.09`，因此界面 DR=67 对应约 58.67 dB，并不是 67 dB。
- Gain 约 0.1705 dB/UI 档；TGC 约 0.06559 dB/UI 档，以 127 为中位。
- 真实 C(z) 取自匹配场次和配置的标定；基础仿真不应直接套用实机某一位置的 C(z)。

以上数值本次检查了代码和协议，未重新拟合实验。不能把它们的精度扩展到所有模式、深度、滑块端点和未验证组合。应以独立于拟合数据的 Gain/TGC/DR 扫描评价后端预测误差，尤其检查暗端、亮端和联合变化。

### 3.3 空间、模式与幅度规范

1. 指标在 mm 坐标下计算；网络输入可以统一尺寸，但同时提供物理尺度、有效区域和目标位置。不要用单纯 resize 消掉 Depth 的意义。
2. 跨 Depth 比较同一任务 ROI，并要求目标完整覆盖；看不见的目标属于覆盖失败，不能被略过后只评估剩余目标。
3. 同深度背景 ROI 用于目标对比，避免把衰减梯度误当作囊肿对比。
4. 保留固定参考的 dB 图。若网络还需要逐图归一化副本，额外保存被减去的偏置；跨前端评估不使用每张图的最大值归一化结果。
5. GEN 与 THI 分开建模，输入真实 TX 频率及模式。THI 的屏显接收频率不能与 GEN 的 TX 数字混为一谈。
6. 当前仿真不包含完整 THI 链路。通用后端曝光/结构特征可以尝试迁移到 THI，但能否改善必须做实机留出验证，不能预先断言一定有效或完全无效。

## 4. 没有理想图像 GT，质量如何定义

### 4.1 可用的四类监督

| 监督来源 | 可以支持什么 | 不能宣称什么 |
|---|---|---|
| 仿真结构真值 | 囊肿 ROI、点靶位置、覆盖率、分辨率和检测评价 | 掩膜不是理想 B-mode 图像 |
| 实机体模几何与少量 ROI 标注 | 同一靶点的物理测量、跨参数配对比较 | ROI 不是最佳 Gain/TGC 标签 |
| 同位置参数扫描、重复 S0 | 质量差分、漂移估计、改进显著性 | 相邻文件不自动代表同一场景 |
| 已知后端变换和优化教师 | 扰动恢复、动作建议、排序伪标签 | 恢复采集默认值不代表恢复最优值 |

可以从“无理想参考图像”的方法开始；它仍包含任务定义、结构先验和人工选择的权衡。若完全不允许任何结构标注，则先限制在可靠识别的均匀区及保守显示约束，避免声称拥有客观完整的前端质量标尺。

### 4.2 前端质量：采集到了什么

建议输出质量向量，按任务选择分量，而不是直接混成一个无法解释的分数。

| 分量 | 计算域与做法 | 防止的错误 |
|---|---|---|
| 目标覆盖 | 目标物理位置、边界余量 | Depth 缩小后丢失深部靶点却得高分 |
| 点靶分辨率 | 显示前包络，峰值相对幅度 −6 dB 宽度，轴向和横向分别以 mm 报告 | 把显示对比或像素放大当分辨率 |
| 囊肿可分辨性 | 固定目标 ROI 与同深度背景，计算 gCNR；必要时评价边缘、尺寸误差 | 单靠 CNR 被压缩曲线“刷分” |
| 穿透/弱目标保留 | 目标区域相对独立估计的噪声或杂波底，并给估计置信度 | 把增益抬高后的噪声当有效组织 |
| 采集代价 | 实际帧率、重采次数、切换时间 | 只顾单帧指标忽略闭环效率 |

gCNR 的定义为：

\[
gCNR=1-\int\min(p_{target}(u),p_{background}(u))du.
\]

在对两个区域施加同一个可逆单调强度变换、且使用理想分布时，重叠量保持不变；有限直方图、裁剪、量化和空间不同增益会破坏这种理想不变性。采用固定 ROI、固定估计流程并报告敏感性，不把 gCNR 当作万能真值。原始依据见 [Rodriguez-Molares 等，2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC8354776/)。

点靶指标要设可靠性门槛：孤立目标、未饱和、峰值显著、足够采样；不可靠时标记缺失，不能只删掉差图中的难测靶点。对检测失败另加漏检惩罚。

不能用最大梯度、最大熵、最大的 speckle mean/std 单独选前端。噪声、复合、散射体密度均可改变它们；Rayleigh 幅度比约 1.91 只是在满足假设时的统计参照，不是通用“好图”标签。

### 4.3 后端质量：把已有信息显示出来

建议后端损失为以下受约束代价，权重和阈值只在训练/验证集确定：

\[
J_{BE}=w_cL_{clip}+w_bL_{brightness}+w_uL_{uniform}
+w_nL_{noise}+w_vL_{visibility}+\lambda_s\|D_2t\|^2.
\]

- Lclip：有效组织里的欠曝、过曝；囊肿内正常黑色不算欠曝。
- Lbrightness：组织中位灰阶落在可接受区间即可；不强制所有组织变为一个值。
- Luniform：同类背景组织在不同深度的稳健亮度差；排除囊肿、镜面点靶、声影和真实组织分层。
- Lnoise：可信噪声/低信号区过度提亮的惩罚；噪声估计不可信时停止自动大幅提升深部 TGC。
- Lvisibility：渲染后目标仍可分辨、边界没有被裁剪淹没；与原始包络的采集质量指标分开报告。
- 二阶差分正则：避免 TGC 剧烈振荡；必要时使用很弱的灰阶利用率项作平局裁决，而不追求直方图占满。

组织掩膜应从控制前的信号、结构信息或固定基准产生，在一次候选搜索中保持不变。否则控制器可能通过改变亮度把难点从评分区域中移走。没有有效组织或可信指标时应返回“不可判定”，而不是零损失或好图。

### 4.4 现有 objective.py 最应先核查的假设

当前 `J=3*crushed+3*saturated+uniformity+utilisation` 可以作为起点，但建议先改进以下部分，再大规模生成标签：

1. `noise_floor_db()` 将最深 10% 的中位数当作噪声。当前仿真没有加电子噪声；海信浅 Depth 的底部也可能仍是组织，不能通用。应使用独立噪声测量、经验证的低信号区，或带置信度的组织/噪声估计。
2. `signal_mask()` 的“高于底部中位数 3 dB”不保证排除囊肿杂波，也会漏掉弱组织。仿真先用结构掩膜校验，实机以少量固定 ROI 验证。
3. 当前没有明确惩罚把噪声/囊肿残余提亮。拉大灰阶范围可能提高评分但损害任务表现。
4. 只检查输出评分变好不够。需要另设未参与优化的目标检测、尺寸或盲评指标，防止循环论证。
5. 文档中“最优搜索不受实机合成验证范围限制”的说法不宜用于真实控制。搜索目标和合成扰动可以采用不同集合，但实机教师标签仍应受硬件边界和标定可信域约束。越界标签只能标为外推待验证。
6. `solve_tgc_levels()` 当前按完整深度带计算统计量，需增加背景掩膜、置信度、平滑约束以及 Gain/TGC 解耦；不能直接当作所有体模上的最优标签生成器。

## 5. 分层闭环如何落地

令前端状态 a=(D,f,zF)，后端动作 b=(G,t1,…,t8,DR)。数学上有 13 个控制量，模式暂时作为固定上下文，不扩展为第七类控制。

### 5.1 后端快环

同一份显示前数据可反复渲染，不需要重复发射。先用背景组织的深度趋势解一个平滑、有界的 TGC，再搜索 Gain 与 DR，最后以坐标下降对三者联合细化。

Gain 与 TGC 有一个可辨识性问题：给所有 TGC 增加同一常量，同时减去等量 Gain，会产生同一 dB 图。建议约束 ROI 加权平均 TGC 为零，把整体亮度交给 Gain；执行器边界下联合投影或选择等效解中离当前状态最近的解。

\[
\min_{g,t}\sum_j q_j\rho(m_j+g+(Bt)_j-m_j^*)+\lambda\|D_2t\|^2,
\quad \sum_jq_j(Bt)_j=0.
\]

q 为有效组织置信度，ρ 可用稳健损失。深部没有可信组织时不强求补平。DR 采用少量实际可设置档位枚举；不要把连续预测直接当作机器可执行档位。

不要枚举八维 TGC 的笛卡尔积。第一版用此确定性求解器就能建立可复现基线；神经网络的价值主要是快速初始化或更好地识别可补偿组织。

### 5.2 前端慢环

\[
b^*(a)=\arg\min_{b\in\mathcal B_{trusted}(a)}J_{BE}(R(E_a,b)),
\]
\[
a^*=\arg\max_{a\in\mathcal A_{observed}}\{Q_{acq}(E_a;ROI)-\alpha J_{BE}(R(E_a,b^*(a)))-\beta C_{acq}(a)\}.
\]

第一步先明确目标 ROI 和深度覆盖。可从最小的、能完整覆盖目标且留余量的 Depth 起步，但最终需要比较真实采集质量和帧率，不能仅凭裁剪选深度。

随后比较频率与焦点。小网格优先穷举已观测候选，或在有限采集预算下使用邻域搜索；只有在线采集代价成为主要瓶颈时，再引入离散、带噪声的 Bayesian Optimization。

历史数据由频率子块与焦点子块构成，不是全部 D×f×focus 组合的完整测量。某些实验下交互弱，只能支持局部近似。对未采组合，代理模型输出预测和不确定性，不能回放出“真实帧”。离线评分必须限制在确实可到达、同位置且已采的候选集合。

用原始信号指标判断采集质量，同时让所有候选先经过相同规则的后端调优，避免单纯欠曝决定频率输赢。原始域质量和最优可显示质量应并列记录。

### 5.3 接受、回退与停止

```text
固定目标 ROI、模式、场景与候选动作边界
读取当前显示前数据，检查场景稳定性和数据有效性
在可信边界内优化后端，渲染并检查约束
预算允许时：选择下一个前端候选，实采或查同场景已采记录
对候选重新优化后端，评价质量向量和目标覆盖
改进超过重复测量波动且约束通过：接受；否则保留当前最佳
低置信度、场景移动、预算耗尽或无显著改进：停止/重置
```

改进阈值来自 S0 或独立重复采集；单图像的像素 bootstrap 不能替代实际重采噪声。限制每步变化量、保存最佳状态、设置死区，防止临近等效最优档位往返切换。

若多个参数组合质量差异小于不确定性，输出等效最优集合，并选择动作较小者。此时没有唯一的参数真值；用参数 MAE 评价会错罚本来同样好的解。

## 6. 后续如果需要 AI，怎样训练

### 6.1 先生成教师，再训练加速器

在训练场景上运行已验证的约束优化器，保存 top-K 解、各质量分量、可信区间、可执行边界与求解状态。称为“目标函数下的近优解/伪标签”。不要把原有 Gain、TGC 曲线或默认截图设为最佳标签。

从同一 envelope 或 BC0 在线抽取已知后端扰动，输入当前参数、图像与 dB 特征，训练模型给出修正。扰动能产生很多训练对，但不会增加独立场景数量。

可恢复当前设置的自监督任务只教会“旋钮如何影响显示”；必须通过独立质量目标才能决定“应当调到哪里”。只恢复人为扰动之前的设置，最终会学习回到原始采集值。

### 6.2 模型建议

| 阶段 | 推荐 | 输出 |
|---|---|---|
| 首个可验证版本 | 有界稳健拟合 + 离散搜索 | G/TGC/DR 与质量向量 |
| 后端学习加速 | 深度统计特征 MLP，或轻量 CNN 加参数分支 | G、零均值 TGC、DR 候选、置信度 |
| 前端候选排序 | 配对质量模型或小型参数响应模型 | 候选质量差与不确定性 |
| 结构掩膜需要自动化时 | 用仿真结构标注训练的小型分割模型 | 背景/囊肿/点靶/不可靠区域 |

数据规模下不建议从零训练大型 ViT 或直接端到端强化学习六参数策略。现有实机数据缺少广泛状态转移和动作覆盖，奖励也尚未经过独立验证。

后端损失可组合动作教师损失、可微渲染质量、平滑正则：

\[
L=\lambda_a\min_{b\in\mathcal B_\epsilon}\|\hat b-b\|_{scaled}^2
+\lambda_qJ_{BE}(R(E,\hat b))+\lambda_s\|D_2\hat t\|^2.
\]

使用等效近优集合可以减轻不可辨识性；可微渲染训练与真实 uint8 渲染分开，最终用真实离散动作验证。

前端排序只对高置信度质量差生成标签，例如 logistic pairwise loss；差值小于测量波动时记为平局。来自指标的伪排序本质上是指标蒸馏；若目标是操作者偏好，需要额外的盲选对或任务表现来补充信息。

### 6.3 划分与迁移

- 保留仿真现有 scene-level split。同 seed 的全部前端设置、所有数字扰动必须在同一集合。
- 如果既有指标、超参已参考了当前 test 场景，则这些场景不能再充当最终未见测试集；应将其归入开发集并生成新 seed 或留出新场次。
- 实机按探头位置和场次分组；同位置跨日期或模式的高度相关数据也需检查关联。位置 ID 不应由平均亮度推断。
- 标定文件的拟合与检验分开。若部署允许用当前场景的一张基准截图做在线标定，测试时可以模拟该流程，但必须明确计算了这项校准成本。
- 先验证 Field II→GEN，再单独验证 THI。允许对通用特征迁移做消融，不能把仿真中不存在的 THI 频率响应直接当教师。
- 用合理的噪声、衰减、固定增益偏置等扰动提高鲁棒性；目前没有电子噪声，若只有包络可用，幅度扰动只是近似，不应声称实现了真实通道噪声。更物理的噪声补充应在 RF/IQ/包络检测之前完成。

## 7. 不依赖最佳图像 GT 的验收设计

先分开回答三个问题：后端模拟是否可信、优化是否改善目标任务、模型是否在有限预算内达到教师表现。

1. 后端标定：在未参与拟合的实测 Gain/TGC/DR 设置上，比较截图的背景亮度、深度趋势、裁剪比例和目标显示。不能把同一帧估计 C(z) 后的重建误差当作跨设置预测精度。
2. 后端控制：对同一观测施加不同初始扰动，记录目标可见性、曝光、背景均匀性、噪声提亮、滑块饱和率、收敛步数及时间。
3. 前端控制：从多个已采起点出发，在相同候选预算下比较默认设置、随机搜索、邻域搜索和所提方法；给出相对于该已采候选集合穷举最优的 regret。
4. 独立质量：点靶 −6 dB 宽度、囊肿 gCNR、覆盖/漏检率、边界或尺寸误差，以及必要时的盲选偏好。至少一项验收指标不参与教师优化。
5. 泛化：新仿真 seed、新探头位置、独立实采场次；以场景为统计单位。对同一张 BC0 的千次扰动不能当千个独立病例来计算置信区间。
6. 消融：无前端调优、无后端调优、无噪声约束、无结构掩膜、无仿真预训练；分别说明哪一部分带来改进。

最终可支持的结论是：“在这些体模任务和已验证参数范围内，系统在有限重采预算下改善了预先定义的目标可见性与显示质量。”不能由当前体模结果直接推出普适临床最优。

## 8. 建议实施顺序

| 优先级 | 产出 | 完成标准 |
|---|---|---|
| P0 | 全量 manifest 和场景/用途分组 | 区分 263 原始导出与网格、标定、重复数据；记录精确参数、位置、模式 |
| P0 | 信号域与标定可信范围 | 保留原始幅度、使用真实坐标、核对 DR 单位、独立检验 C(z) 与后端模型 |
| P1 | 有 ROI 和有效性标志的指标集 | 修正噪声底假设；覆盖失败、空掩膜、低置信度不会得到好分 |
| P1 | 后端基线求解器 | 8 滑块有界平滑、与 Gain 解耦、Gain×DR 搜索、逐项质量日志 |
| P2 | 有限动作前端回放 | 仅用同场景已采状态，比较共同目标 ROI，报告有限网格 regret |
| P3 | 伪标签与轻量模型 | 按场景划分；标明教师/标签版本、等效最优集合、边界与置信度 |
| P4 | 新场次主机验证 | 完成实际参数改变→重采→评价→接受/回退，记录耗时与失败案例 |

最值得补充的数据是少量新位置的同任务参数配对、可信噪声/低信号参考，以及标定可信范围边缘的验证帧。它们比继续增加相同 BC0 的显示扰动，更有助于降低当前的不确定性。
