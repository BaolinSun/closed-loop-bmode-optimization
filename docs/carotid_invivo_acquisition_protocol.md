# 人体颈动脉数据采集方案 —— 六参数闭环优化（v1.1）

日期：2026-09-24；2026-10-08 改为只用谐波成像（现场询问医生，临床上基本只用谐波），基波完整块全部取消。逐帧执行列表见 [carotid_invivo_acquisition_checklist.md](carotid_invivo_acquisition_checklist.md)。主机：海信，L15-4 线阵探头，颈动脉预设。规模：约 300 名受试者。

用途：为 **深度、频率、聚焦、增益、TGC（时间增益补偿）、动态范围** 六参数闭环优化提供人体训练、微调与验证数据。本方案建立在体模协议 [phantom_acquisition_protocol_v4.md](phantom_acquisition_protocol_v4.md)、实机训练数据分析 [console_training_data_20260914.md](console_training_data_20260914.md)、Field II 标签 [fieldii_labels_20260915.md](fieldii_labels_20260915.md) 与网络文档 [six_parameter_network_20260915.md](six_parameter_network_20260915.md) 的结论之上；凡引用的数字都来自这些文档或 `runs/` 下的训练结果。

## 0. 一页摘要

| 决定 | 内容 | 依据（详见对应章节） |
|---|---|---|
| 采什么 | 每个切面在**同一探头位置**上，采「专家调优帧 + 以专家设置为中心的频率/聚焦/深度三组扫描」，约 30 人另加后端阶梯 | 前端标签只能由同一场景的多帧比较得到；后端标签从单帧即可合成（§2、§6） |
| 切面 | 核心 4 个 × 左右两侧：颈总动脉横切、颈总动脉纵切、分叉部横切、分叉部纵切；**建议增加**颈内动脉近段纵切、椎动脉椎间段纵切；有斑块时加斑块切面 | 各切面对六参数的作用不同，增加的两个切面补「目标更深」这一空白（§4） |
| 成像模式 | **只用谐波成像**，全部切面都做完整扫描 | 临床上基本只用谐波；预设工作点也是谐波（§6、§7） |
| 受试者 | 300 人，按年龄 × 体重指数分层，性别均衡；**按人**事先划分训练 / 验证 / 测试，分两期采集 | 独立单位是人，不是帧（§3） |
| 动态范围 | 不靠扫描，靠**离线成对偏好阅片**：同一帧原始数据渲染成不同动态范围，由多名医生盲选 | 两个数据源都没有动态范围判据，人的偏好是唯一来源（§10.3） |
| 标定 | 每名受试者用表二自己的帧拟合标定（医生不动滑块，全部帧都是拉平的）；后端阶梯与复位复现只在约 30 人上做 | 标定按（场次，成像模式）拟合，不能借用；借用会让增益建议顶到限幅（§6.5、§6.6） |
| 质控 | 每日体模质控；受试者离开前现场检查；每 50 人阶段复盘 | §8、§9 |
| 预实验 | 正式采集前 10 人，冻结阈值与流程 | §14 |
| 每人时长 | 标准版约 37 分钟（其中存图约 257 帧）；精简版约 28 分钟 | §7 |

## 1. 术语与简写

正文尽量写中文全称；下表列出仍会出现的简写。

| 简写 | 全称 | 含义 |
|---|---|---|
| TGC | Time Gain Compensation | 时间增益补偿。本机是触摸屏上 8 个滑块，取值 0–255，**只能拖到大致位置，不能输入数值**；实际值从导出文件 `BEParam.pdt` 读 |
| DR | Dynamic Range | 动态范围。本机界面数字 30–400 **不是 dB**，有效窗宽 = 0.352 × 界面数字 + 35.1 dB |
| BC0 | `Algo_BC0.bin` | 主机导出的对数域包络扫描线数据，在增益、TGC、动态范围之前，所以不受这三者影响 |
| 谐波成像 | 组织谐波成像（`BImageMode` = 1） | 发射 f、接收 2f；屏显频率是接收频率 |
| 基波成像 | `BImageMode` = 0 | 发射 f、接收 f。**不称「通用模式」** |
| CCA | Common Carotid Artery | 颈总动脉 |
| ICA / ECA | Internal / External Carotid Artery | 颈内动脉 / 颈外动脉 |
| IMT | Intima-Media Thickness | 内中膜厚度 |
| BMI | Body Mass Index | 体重指数 = 体重(kg) / 身高(m)² |
| ECG | Electrocardiogram | 心电图 |
| MI | Mechanical Index | 机械指数，声输出安全指标 |
| ROI | Region of Interest | 感兴趣区，本文指血管及其前后壁所在区域 |

本文专用的采集块代号（§6）：**R** 专家调优帧（兼参考帧）、**F** 频率扫描、**Z** 聚焦扫描、**D** 深度扫描、**B** 后端阶梯、**N** 噪声底帧、**Q** 复位复现帧。

## 2. 为什么要采人体数据：现有数据的缺口

### 2.1 现有训练结果说明了什么

| 数据与模型 | 结果 | 含义 |
|---|---|---|
| 海信实机微调，4 折（`runs/console_ft_final_v2`） | 增益平均误差 1.28 dB，只看设置的查表基线 1.37 dB；频率方向 F1（F1 为精确率与召回率的调和平均）0.47，查表基线 0.70 | 网络在实机上**几乎没有胜过「记住这个体模」**，频率方向甚至不如查表 |
| 实机标签本身 | 只用（成像模式、显示深度、当前频率）不看图像就能猜中频率方向 **95%** | 全部 422 帧来自**同一个体模**，衰减均匀、靶的深度固定，标签近似查表 |
| Field II 最终模型测试集（`runs/fieldii_final`） | 增益 0.19 dB、TGC 0.16 dB、频率命中 0.80、聚焦 0.84；闭环 96% 停下 | 仿真上模型确实会看图，但仿真没有谐波、没有真实组织分层 |
| 实机过滤后的前端比较集 | 深度 19、频率 26、聚焦 17，合计 **62** 个 | 前端监督量太少，按摆放切分时测试集常常为空 |
| 动态范围 | 两个数据源的 `dr_determined` 全部为假 | **没有判据，六个参数只能训五个** |
| 体模上的最优聚焦 | 实机最优恒在 10–25 mm；体模钢丝靶焊死在约 12 mm 深 | 体模永远给不出「目标更深、聚焦应更深」的样本 |

### 2.2 人体数据要补的四个缺口

1. **场景多样性。** 每个人的颈部厚度、皮下脂肪、肌肉衰减、血管深度都不同。同一设置下的最优频率、深度、聚焦会随人变化，模型才必须看图。这是 95% 可猜问题的唯一根本解法。
2. **有明确目标的前端判据。** 体模的深度规则是「底部仍高出噪声底 6 dB 的最深一档」，与任务无关。人体上有明确目标（血管远壁），深度要盖住远壁，频率要在远壁处仍有余量，聚焦要落在目标附近。这需要标注血管位置（§10.1）。
3. **动态范围的监督。** 只能来自人的偏好（§10.3）。
4. **人体图像上的后端目标。** 体模上的目标亮度取自体模场次，TGC 目标是「均匀介质各深度一样亮」。人体组织本来就分层（脂肪偏暗、筋膜偏亮），不能照搬「各深度一样亮」。专家调优帧与偏好阅片用来标定人体上的目标亮度与深度走势（§11）。

### 2.3 人体数据做不到的事

- **没有「最优图像」真值。** 标签仍是判据加专家偏好的产物，本方案只保证判据可检验、专家偏好可量化一致性。
- **做不了全网格。** 手持探头无法在一个位置停留几分钟，前端只能做「以专家设置为中心的三条单轴扫描」，不是深度 × 频率 × 聚焦的全组合。
- **不替代 Field II 与体模。** 训练链路仍是 Field II 预训练 → 体模微调 → 人体微调；噪声底、分辨率表这类探头属性仍以体模测量为准。

## 3. 受试者

### 3.1 规模与分层

300 人。按两个对图像物理影响最大的因素分层，每层人数大致相等：

| | 体重指数 < 24 | 24–28 | ≥ 28 |
|---|---|---|---|
| 18–39 岁 | 33 | 33 | 33 |
| 40–59 岁 | 33 | 33 | 33 |
| ≥ 60 岁 | 34 | 33 | 34 |

- **体重指数**决定皮下脂肪与血管深度，直接影响穿透、深度、频率。体重指数 ≥ 28 的受试者在普通招募里偏少，要主动招募。
- **年龄**决定斑块、钙化与声影的出现率，60 岁以上组预计有较多斑块（§4.3）。
- 每层内男女各半。
- 另记录颈围（在甲状软骨下缘水平量），它比体重指数更直接地反映颈部厚度。

### 3.2 纳入与排除

- 纳入：18 岁以上，能平卧 45 分钟，颈部可自然后仰并向对侧转头。
- 排除：颈部近期手术或外伤、颈部皮肤破损、颈动脉支架或内膜剥脱术后（可作为单独的少量病例另行记录，不进入主分层）、已知颈动脉窦过敏或晕厥史、不能配合平静呼吸。

### 3.3 伦理与安全

- 须经伦理委员会批准，受试者签署知情同意书。这是研究性采集，不出诊断报告；发现明显狭窄或大斑块时，按伦理方案告知受试者就医。
- 声输出：全程使用颈动脉预设的声功率（`GPowerPer` = 100%），机械指数随频率档在 0.385–0.605 之间（谐波 5 档），不超过预设范围；每人扫查时间控制在 45 分钟内。
- **分叉部轻压**：颈动脉窦在分叉部，压迫可引起心率减慢或血压下降，老年人尤其要注意。分叉部切面只用维持耦合所需的最小压力；受试者诉头晕立即停止。
- 脱敏：主机上每名受试者新建一个检查，姓名栏只填受试者编号，不填出生日期（§13）。

### 3.4 划分：按人，事先定好，分两期采

- 同一个人的所有切面、所有帧、左右两侧必须在同一集合（同一人左右两侧解剖高度相关）。
- 按分层表在每层内随机分配：**训练 200 人 / 验证 50 人 / 测试 50 人**，招募前生成分配表并冻结。
- **两期采集**：第一期 250 人（训练 + 验证），第二期 50 人（测试）。第二期在模型用第一期数据训练完成之后采，并在这 50 人身上做人体闭环实测（§12）。测试集因此还检验了时间跨度上的稳定性（主机、探头、操作者在几个月里的变化）。
- 操作者也是一个因素：记录每一帧的操作者编号；测试集里每名操作者都要有受试者。

## 4. 切面

### 4.1 四个核心切面：各自对六参数的作用

| 切面 | 典型图像内容 | 对六参数的主要作用 |
|---|---|---|
| **颈总动脉横切**（分叉下方 2–3 cm） | 圆形管腔、旁边的颈内静脉、前方甲状腺与肌层 | 画面里有大块无回声区（动脉 + 静脉），检验增益 / TGC 不去「提亮血管腔」；近场层次多，考验近段 TGC |
| **颈总动脉纵切**（远段，分叉下方约 1 cm 的远壁，即内中膜厚度测量的常规标准切面） | 平行的前后壁、远壁内中膜 | 临床最重要的切面；聚焦应落在远壁附近，频率要高而远壁仍有余量——**聚焦与频率的主力切面** |
| **分叉部横切** | 膨大的球部，颈内、颈外动脉分开 | 管腔更大、更深；斑块好发 |
| **分叉部纵切** | 球部与分流嵴，颈内动脉向深部走 | 目标深度沿横向变化，考验深度与 TGC 的取舍；斑块好发 |

左右两侧都采：解剖不完全对称，且两侧的深度、斑块情况不同，等于额外的场景。

### 4.2 建议增加的两个切面

| 切面 | 为什么加 | 对六参数的作用 |
|---|---|---|
| **颈内动脉近段纵切**（分叉以上 1–3 cm） | 颈内动脉向后深处走，常见在 25–40 mm | 需要更深的显示深度、更低的频率，让最优深度的分布向深处展开——体模上最优深度 69.5% 集中在 41.9 mm |
| **椎动脉椎间段纵切**（第 3–6 颈椎横突之间） | 位置深（常见 30–45 mm），两侧有横突造成的周期性声影 | **穿透与频率取舍最强的切面**；声影区不应被 TGC 拼命提亮，考验组织掩膜对声影的处理 |

这两个切面仍在同一探头、同一预设下完成，额外时间约 5 分钟（谐波完整块，两侧）。

### 4.3 条件切面：有斑块时加

- 发现斑块（局部增厚 ≥ 1.5 mm 或突入管腔）时，在斑块最厚处加一个纵切、一个横切。
- **低回声斑块与血液之间的对比度只有几个 dB，这正是体模协议 E10 一直缺的「低对比度靶」**：动态范围、增益设得不对，软斑块就会看不见。它们是动态范围偏好阅片的重点样本（§10.3）。
- 钙化斑块后方有声影，与椎动脉切面一样用来检验掩膜。
- 记录斑块回声类型（低 / 等 / 高回声，是否伴声影）。

### 4.4 可选切面

| 切面 | 作用 | 何时采 |
|---|---|---|
| **甲状腺横切**（一侧） | 甲状腺实质回声均匀，是人体上最接近「均匀体模」的组织，适合做增益 / TGC 的干净参照；位置浅，频率应取高档 | 时间允许时；只做 P + R + B（7 帧）。仍用颈动脉预设，不切换到甲状腺预设 |
| **颈总动脉纵切的第二入路** | 前入路、侧入路、后入路看到的血管深度与上方组织不同，便宜地增加深度多样性 | 每 3 人中 1 人，只做谐波完整块 |

### 4.5 不采的内容

| 不采 | 原因 |
|---|---|
| 彩色多普勒、频谱多普勒下的图像 | 改变帧率与处理链，BC0 不再是纯 B 模式 |
| 局部放大（Zoom） | 改变几何，`BZoomValue` 必须为 1.0 |
| 梯形扩展成像、声束偏转 | 改变几何与复合；`BExtendLevel` = 0，`BSteerValue` = 0 |
| 双幅、四幅分屏 | 截图的图像区位置改变，标定读不出 |

### 4.6 切面汇总

| 优先级 | 切面 | 侧别 | 完整块 | 后端阶梯 |
|---|---|---|---|---|
| 必采 | 颈总动脉横切 | 双侧 | ✓ | — |
| 必采 | 颈总动脉纵切 | 双侧 | ✓ | 约 30 人的 B 侧（另加复位复现） |
| 必采 | 分叉部横切 | 双侧 | ✓ | — |
| 必采 | 分叉部纵切 | 双侧 | ✓ | 约 30 人的 B 侧 |
| 建议 | 颈内动脉近段纵切 | 双侧 | ✓ | — |
| 建议 | 椎动脉椎间段纵切 | 双侧 | ✓ | — |
| 条件 | 斑块纵切 + 横切 | 有斑块一侧 | ✓ | — |
| 可选 | 甲状腺横切 | B 侧 | 只做 P、R | ✓ |
| 可选 | 颈总动脉纵切第二入路 | 一侧 | ✓ | — |

「B 侧」按受试者编号奇偶交替：奇数号为右侧，偶数号为左侧。

## 5. 主机设置

### 5.1 整个研究固定不动的设置

下表来自体模协议 §5c.2，全部 263 帧历史数据这些项从未变过；人体采集保持一致，历史标定才能与人体数据比较。**每天开机后按表核对一次**，§9 的检查脚本也会逐帧从 `.pdt` 里核对。

| 项 | 应为 | 参数名 |
|---|---|---|
| 探头 | L15-4 | `ProbeID` = 21 |
| 检查预设 | 颈动脉 | `ExamModePreset`；`AnnoTextInfo.pdt` 里 `nImageExamName` = 颈动脉 |
| **自动优化** | **关** | `BAutoOptimize` = 0。开着主机会自己改增益与滑块 |
| 侧向增益补偿 | 关 | `BUseLGCMode` = 0 |
| 灰阶曲线 | 2 | `BMapLevel` = 2 |
| **色调（调色板）** | **1** | `BTintLevel` = 1。改了它，截图反解出的灰阶全部作废 |
| 边缘增强 / 图像增强 / 斑点抑制 / 平滑 | 2 / 3 / 2 / 3 | `BEdgeEnhanceLevel` / `BImageEnhanceLevel` / `BHipureLevel` / `SmoothLevel` |
| 回波增强 / 背景噪声抑制 | 0 / 0 | `BEchoBoostLevel` / `BackNoiseRejectLevel` |
| 空间复合、线密度 | 预设默认 | `BSpatialCompLevel`、`BDensityLevel` |
| 偏转、扩展、放大 | 0 / 0 / 1.0 | `BSteerValue` / `BExtendLevel` / `BZoomValue` |
| 左右、上下翻转 | 关 | `BLeftRightFlipFlag`、`BUpDownFlipFlag` |
| 声速 | 1540 m/s | `TsiValue` |
| 声功率 | 100% | `GPowerPer` |
| 发射焦点个数 | 1 | `BFocusNumValue` = 1 |

另记录主机软件版本与探头序列号；研究期间主机升级或换探头，必须当天在日志里注明，并重做 §8 的体模质控。

### 5.2 六个参数的档位

| 参数 | 控件 | 档位 |
|---|---|---|
| 深度 | 硬件摇杆 | 25.1 / 33.5 / 41.9 / 50.2 / 58.6 / 67.0 / 75.4 mm |
| 频率（谐波成像） | 触摸屏「图像质量」 | 发射 4.4 / 4.7 / 5.0 / 5.3 / 5.7 MHz。屏显：2026-10-08 固件升级前为单个数字 8.8 / 9.4 / 10.0 / 10.6 / 11.4，升级后为范围 6.2~11.4 / 6.6~12.2 / 7.0~13.0 / 7.4~13.8 / 8.0~17.0 |
| 聚焦 | 触摸屏「焦点位置」 | 5 mm 起、步长 5 mm；上限 = max(40, 5 × ⌊显示深度 / 5⌋) mm |
| 增益 | 硬件旋钮 | 0–255；谐波约 0.205 dB/级 |
| TGC | 触摸屏 8 滑块 | 0–255，只能拖到大致位置；**「平档」用预设曲线里那条竖直线，不要手拖** |
| 动态范围 | 触摸屏「动态范围」 | 界面 30–400，不是 dB |
| 成像模式 | 触摸屏「基波 / 谐波」 | **固定为谐波成像** |

### 5.3 每名受试者新建一个检查

主机按检查把采集存到 `D:/PatientData/<日期>/<日期_时间_检查号>/…`。每名受试者开始前新建检查，姓名栏填受试者编号（如 `CA0123`），其余个人信息留空。这样一名受试者的全部采集自然落在一个目录里，也就是一个**场次**——标定按（场次，成像模式）进行（§6.5）。

## 6. 每个切面的采集流程

### 6.1 采集块

每个切面在找到稳定的标准切面、**探头位置不再改变**之后，按下列块采集。一个切面的全部块合称一个**完整块**。每一帧的具体参数见逐帧列表 [carotid_invivo_acquisition_checklist.md](carotid_invivo_acquisition_checklist.md)。

| 块 | 帧数 | 做什么 | 训练用途 |
|---|---|---|---|
| **R** 专家调优帧 | 1 | 医生按自己的临床习惯把六个参数（含深度、频率、聚焦）调到最满意，存一帧 | 专家偏好；三组扫描的中心；运动检查的参考帧 |
| **F** 频率扫描 | 5 + 1 | 深度、聚焦保持 R，谐波 5 档频率（FHNor、HPen、HPenMid、PHNor、HRes）各存一帧，最后回到 R 再存一帧 | 频率比较集 |
| **Z** 聚焦扫描 | 6 + 1 | 深度、频率保持 R，聚焦 10 / 15 / 20 / 25 / 30 / 35 mm 各存一帧，最后回到 R | 聚焦比较集 |
| **D** 深度扫描 | 6 + 1 | 频率、聚焦保持 R，深度 25 / 33 / 42 / 50 / 59 / 67 mm 各存一帧，最后回到 R | 深度比较集；67 mm 那帧兼作噪声底 |

完整块 = R 1 + F 6 + Z 7 + D 7 = **21 帧**，每个切面都相同。逐帧列表见表二。

说明：

- **2026-10-09 修改**：不再采预设起点帧；医生的调优帧连深度、频率、聚焦一起由医生自由决定；三组扫描以医生的设置为中心。
- 每个比较集的条件就是医生选的另外两轴，与标签的求解顺序（聚焦 → 频率 → 深度，每一步都以另外两轴为条件）对得上。
- **每组扫满全部档位，不跳过医生自己那一档**：每组因此多一帧与 R 相同的设置，每个切面最多多 3 帧，约 10 秒；换来的是医生照表拨档、不必临时判断跳过哪一档。这几帧与 R 设置相同，也是额外的运动检查点。
- **每组扫描结束时回到 R 再存一帧**：这 4 帧 R（开头 1 + 每组末尾 3）设置完全相同，BC0 应当只差运动与心动，用来做运动检查（§6.3）。
- 扫描期间**增益、TGC、动态范围都不动**，一直是医生在 R 帧调好的值。前端标签在 BC0 上计算，与增益无关；深度扫描到 67 mm 时画面底部变黑是正常的，**不要为此去拧增益**。
- 医生的深度若较浅（如 33 mm），聚焦扫到 35 mm 会比显示深度还深。主机允许，照存；生成标签时自动排除这类组合。

### 6.2 一个完整块的操作表（谐波成像，以颈总动脉纵切为例）

| 步 | 操作 | 存图 | 记录员记 |
|---|---|---|---|
| 1 | 找到标准切面，受试者平静呼吸、不吞咽不说话 | — | 切面代号、侧别 |
| 2 | 医生自由调六个参数到满意 | **R** | |
| 3 | 频率逐档切换 5 档，每档存一帧 | F×5 | |
| 4 | 频率回到 R 的档 | **R** | |
| 5 | 聚焦逐档切换 6 档，每档存一帧 | Z×6 | |
| 6 | 聚焦回到 R 的档 | **R** | |
| 7 | 深度逐档切换 6 档，每档存一帧 | D×6 | |
| 8 | 深度回到 R 的档 | **R** | 本块结束时间 |

历史场次两帧之间的间隔中位数为 1.6–4.9 秒（`data/hisense_medical` 的时间戳），所以一组扫描（5–6 帧）约 15–20 秒，一个完整块约 1.5 分钟。

### 6.3 手持条件下的运动控制

体模上探头夹在支架上，人体上做不到。代之以下列规则：

1. **持探头的手只负责探头，另一只手操作面板。** 体模上曾因切换模式碰到探头，探头移动约 0.4 mm，回程参考帧偏了 1.09 dB（体模协议 §11.3）。前臂或小指靠在受试者颈侧或床面上借力。
2. **每组扫描 15–20 秒，在一次平静呼气后开始**，期间受试者不吞咽、不说话。吞咽会让颈动脉与甲状腺上下移动数毫米。
3. **运动检查**：同一完整块内的 4 帧 R 两两比较。判据用**空间结构**，不用平均亮度（体模协议 §11.5 规则 3：两块完全不同的区域平均电平只差 0.018 dB）：
   - BC0 dB 图的归一化互相关（去掉管腔后计算）；
   - 前后壁位置的偏移（由自动边缘检测或标注得到）。
   
   阈值在预实验中定（§14）。暂定：前后壁偏移 ≤ 0.5 mm，且互相关不低于预实验中「确认未动」那部分帧对的第 5 百分位。某组扫描前后两帧 R 不通过，只重采那一组。
4. 不强求探头支架。若预实验显示手持的重采率超过 30%，再考虑在一部分受试者上用万向臂探头夹持器。

### 6.4 心动与呼吸

- 颈动脉每个心动周期直径变化约 5–10%，前后壁随之移动。单帧 BC0 是某一瞬间，时相随机。
- **后端标签不受影响**（最优增益 / TGC 是图像的属性）。前端比较集里各帧时相不同，会在前后壁附近引入小的差异；R 帧之间的差异正好量出这部分，作为比较集的噪声水平。
- **预实验要确认两件事**：主机是否有心电模块、能否在 R 波（舒张末期）触发冻结存图；存储一段电影回放时 BC0 是否导出多帧（导出文件 `Algo_PartitionInfo.pdt` 里有 `PageNum` 字段，目前历史数据都是 1）。若能导出多帧，每个 R 设置存 2–3 秒电影，时相差异可以直接平均掉，还能免费得到同一设置的多帧样本。

### 6.5 后端阶梯 B（约 30 人）

逐帧操作见表三（[carotid_invivo_checklist_table3.md](carotid_invivo_checklist_table3.md)，2026-10-13 版）。接下来的约 30 名受试者，每人只在**一个**切面上做（一组完整、图像稳定的切面，最好是颈总动脉纵切），接在表二第 21 帧之后，先做复位复现 Q（§6.7），再做下表，第 22 帧找回切面之后探头不能再动：

| 帧 | 设置（相对第 23 帧） | 检验什么 |
|---|---|---|
| B1（第 24 帧） | 增益减 15 格，约 −3 dB | 增益的渲染 |
| B2（第 25 帧） | 增益加 24 格，约 +5 dB | 增益的渲染 |
| B3（第 26 帧） | 增益拨回，动态范围 45 | 动态范围的渲染 |
| B4（第 27 帧） | 动态范围 100 | 动态范围的渲染 |
| B5（第 28 帧） | 动态范围拨回 67，下面 4 个滑块（深处）调高一截 | 时间增益补偿的渲染 |
| B6（第 29 帧） | 再把上面 4 个滑块（浅处）调低一截 | 时间增益补偿的渲染（两段反向） |

做完点预设曲线中的竖直线，滑块恢复拉平。滑块只需拖到大致位置，实际值从导出文件读。

**为什么改**：2026-10-09 到 10-12 的四天数据里，医生全程使用预设，8 个滑块始终拉平、动态范围始终 67，原来最后一帧「滑块拉平」已无意义；而训练时要按任意滑块位置渲染起点，时间增益补偿的渲染在人体上同样需要检验，所以换成两帧真实调动的滑块。原方案要求两个切面，30 人 × 8 帧约 240 帧已足够检验，改为一个切面。

**标定不依赖后端阶梯**：标定函数 `bmode_opt/calibration.py` 的 `_select_fit_frames` 只取滑块完全拉平、且显示缩放未让图像超出窗口的帧。四天数据所有帧都是拉平的，修正截图裁剪（按导出的窗口位置和 PixelGap 计算，见 `hisense_loader.screen_image_bounds`）之后，90 个 L15-4 颈动脉检查中 89 个用表二自己的帧拟合成功，分带误差中位约 2.4 灰阶（旧体模 1.4），各受试者之间标定常数相差约 4%。唯一失败的检查全部帧都在显示缩放 1.6 下，图像超出窗口。**若以后医生开始调滑块，表二就不再有拉平的帧**，届时需要让标定代码接受未拉平的帧（时间增益补偿每格的分贝数已在体模上标定），或每人补拍几帧拉平的帧。

后端阶梯回答的是研究层面的问题，约 30 人足够：

- 增益 −3 到 +5 dB 是体模 E3 验证过的重渲染可信范围。用第 23 帧的 BC0 渲染 B1–B6 的设置，与主机真实截图逐像素比较（体模上约 2.7 灰阶），检验人体组织上重渲染是否可信；动态范围偏好阅片和训练起点的合成都依赖这一点。
- 同一场次有 ≥ 4 种不同的后端设置，才能量出标签不确定度；其余受试者借同模式的中位数。

B 块内 BC0 不变，所以这 6 帧也是免费的运动检查。

### 6.6 噪声底帧 N

频率与深度判据都读「高出噪声底多少 dB」，噪声底必须测。体模上只有显示深度 ≥ 58 mm 且最深处已超出穿透的帧才能量到（显示 67 mm 时深部斜率才降到 −0.06 dB/mm 以内）。人体上分两路测，预实验比较后决定正式采集用哪一路：

| 路 | 做法 | 帧数 |
|---|---|---|
| **N-体内** | D 扫描里的 67.0 mm 帧：颈部 60 mm 以下多为椎体声影或超出穿透 | 每个完整块自带 1 帧，不额外花时间 |
| **N-空载** | 受试者开始前，擦净探头面，探头离体朝上，深度 67.0 mm，谐波 5 档频率各存一帧 | 5 帧，约 20 秒 |

四天人体数据（2026-10-09 至 10-12）中 67 mm 帧的底部全部平坦，各检查之间噪声底相差约 0.1 dB，N-体内已足够，表一的离体空载帧可以取消。电子噪声是接收机的性质，与受试者无关；若预实验证明三路结果（空载、体内深部、体模 67 mm）以 BC0 计数表示时一致，正式采集就把 N-空载改为**每天一次**（并入 §8 的体模质控），每人省 20 秒。

### 6.7 复位复现 Q 与双人对照

- **Q（约 30 人，与后端阶梯同一批受试者，表三第 22、23 帧）**：做表三的那个切面的完整块结束后，探头离开皮肤，重新找到同一切面，保持 R 的全部设置存 1 帧；再由医生重新调到满意存 1 帧。前者量「重新找切面」带来的标签波动，后者量同一医生两次调节的差异。
- **双人对照（30 人）**：第二名医生在同一受试者的颈总动脉纵切与分叉部纵切上独立调到满意，各存 1 帧 R。量医生之间的差异，用来设定闭环的死区与「可接受集合」的宽度——比医生之间的差异还小的调整，没有临床意义。

## 8. 每日体模质控

每个采集日开始前，用体模协议的体模、均匀区、固定的 S0 设置（谐波成像，5.0 MHz，41.9 mm，聚焦 15 mm，TGC 平档，增益与动态范围固定为质控专用值）：

| 帧 | 内容 |
|---|---|
| 3 | S0，间隔拉开（开头、中间、结尾） |
| 5 | 显示深度 67.0 mm，谐波 5 档频率——每日噪声底 |
| 5 | 谐波 5 档频率在 41.9 mm——频率响应的逐日复现 |

约 5 分钟。判据用**相对量**（体模协议 §7.9：四个位置的频率响应一致到 0.22 dB）：逐日的频率响应、噪声底与首日相比超出预实验定下的容差时，当天暂停人体采集，先排查主机与探头。

这份逐日记录同时是整个研究期间主机稳定性的证据，测试集（第二期）晚几个月采，需要它来说明两期数据可比。

## 9. 质量控制

### 9.1 现场（受试者离开前）

导出到采集笔记本，运行检查脚本（**待开发**，建议放在 `tests/verify_invivo_capture.py`），约 2 分钟：

| 检查 | 判据 | 不通过怎么办 |
|---|---|---|
| 固定设置 | §5.1 表内各项逐帧与规定一致 | 找出改动发生的切面，改回后重采该切面 |
| 块完整性 | 每个完整块的帧数与设置序列与计划一致（按记录员的时间表对上） | 补采缺的帧 |
| 运动检查 | §6.3 | 重采该组扫描 |
| 曝光（只查 P、R） | 截图 `gray ≤ 2` 的像素占比 < 30%（体模协议 §6.3） | R 不合格说明专家调节本身有问题，记录但不重采；P 不合格正常（预设不适合此人） |
| 标定可行 | 本人的标定可用像素占比 ≥ 40% | 补一帧滑块拉平的帧（§6.5 兜底） |

### 9.2 当天

- 对当天全部受试者跑 `tools_refit_calibration.py` 的人体版本（需要把会话列表改为按受试者读取，**待开发**），确认每人都有自己的标定，没有借用。
- 核对记录员的时间表与主机时间戳，生成清单（§13）。

### 9.3 每 50 人阶段复盘

- 生成标签，重训一次，画**学习曲线**：用 50 / 100 / 150 / … 人训练时，验证集上各轴指标的变化。
- 用学习曲线决定后续取舍：某一类切面、某种成像模式的加入如果不再提升验证指标，就在后续受试者上削减它，把时间让给提升最多的部分。
- 复查分层表的实际完成情况，缺的层优先招募。

## 10. 标注与阅片

### 10.1 解剖标注

每个完整块只标 R 帧（运动检查通过的块，各扫描帧共用这份标注）；约 300 人 × 13 个切面 ≈ 3900 帧。

| 标注项 | 形式 | 用途 |
|---|---|---|
| 动脉管腔 | 多边形 | 从后端组织掩膜里去掉（管腔是无回声区，与体模囊肿一样不能被判为欠曝） |
| 颈内静脉管腔 | 多边形 | 同上 |
| 近壁、远壁（内中膜） | 折线 | 前端判据的目标区：深度要盖住远壁，频率在远壁处要有余量，聚焦落在目标附近 |
| 斑块 | 多边形 + 回声类型 | 低对比度目标；偏好阅片的重点 |
| 声影 | 多边形 | 从 TGC 目标里去掉，不能靠提亮声影「补平」 |
| 甲状腺、肌层（可选） | 多边形 | 研究人体组织分层对 TGC 目标的影响 |

- 在 BC0 换算的扫描线图像上标注（毫米坐标），不在截图上标——截图有文字、刻度与色表。
- 两名医生，10% 的帧双标，报告一致性（管腔用重叠系数，壁的位置用毫米误差）。
- 前 50 人全部手工标注；之后用这 50 人训练一个分割网络预标注，医生只修改。

### 10.2 专家方向评分（盲评）

对每个切面的 R 帧，以及每组扫描里随机抽 1 帧，由未参与采集的医生在阅片工作站上盲评：

- 整体质量 1–5 分；
- 深度、频率、聚焦、增益各自的方向：偏小 / 合适 / 偏大；TGC 分近、中、远三段各给方向；动态范围：偏窄 / 合适 / 偏宽。

用途不是直接当标签，而是**检验物理判据与医生判断的一致性**：例如频率判据说「可以再升一档」时，医生是否也认为分辨率不够。不一致的地方就是判据需要修改的地方。

### 10.3 离线成对偏好阅片（动态范围与曝光）

这是动态范围获得监督的唯一途径，**不需要额外扫描**：BC0 与动态范围无关，同一帧可以渲染成任意动态范围（体模 E5 已验证 BC0 与动态范围完全无关、动态范围可以从 BC0 模拟）。

做法：

1. 从 R 帧中抽约 600 个（覆盖全部切面，斑块切面加倍抽样）。
2. 每帧用后端模型渲染若干版本：动态范围界面 30 / 45 / 67 / 100 / 150，增益 −3 / 0 / +3 dB，TGC 近场或远场抬高 / 压低一档。
3. 两两并排显示（左右随机），阅片医生选「左好 / 一样 / 右好」。每帧约 10 对，至少 3 名医生。
4. 用 Bradley–Terry 成对比较模型（由成对胜负估计每个版本的潜在得分）得到每帧的偏好得分，取得分最高的动态范围作为该帧的动态范围标签，并给出置信区间；得分之差小于阅片者之间的分歧时记为「并列」。
5. **锚点**：B 块里真实采到的动态范围 45、100 两帧，与渲染出的同设置版本混在一起让医生评，检验「渲染出来的图与真实图在医生眼里是否一样」。

工作量：600 帧 × 10 对 = 6000 次判断 / 人，每次约 4 秒，每名医生约 7 小时，可分多次完成。

增益与 TGC 的偏好结果不替代求解器教师，而是用来**标定教师里的自由参数**：人体组织上的目标亮度、TGC 允许保留多少深度走势（§11）。

## 11. 数据如何变成标签

增益、TGC 与其余参数一样由深度学习网络训练（SixParamNet），求解器只做教师。训练链路：Field II 预训练 → 体模微调 → 人体微调；人体微调沿用实机微调的做法（`--init-checkpoint`、`--freeze encoders`、`--scalar-norm levels`），分组改为按受试者。

| 参数 | 比较集 / 数据 | 判据 | 人体数据要标定的自由参数 | 专家帧的角色 |
|---|---|---|---|---|
| 增益 | 每一帧（起点可重抽合成） | 求解器教师：组织掩膜内亮度达到目标 | **目标灰阶**：由 R 帧的实际亮度与偏好阅片共同标定，按成像模式分 | 目标亮度的来源 |
| TGC | 同上 | 求解器教师：按深度补偿 | **深度走势**：人体组织分层，不能要求各深度一样亮；允许保留多少走势由 R 帧与偏好阅片定 | 同上 |
| 动态范围 | 偏好阅片的 600 帧 | Bradley–Terry 偏好得分最高者 | — | 阅片者即专家 |
| 频率 | F 组 | **改为以目标为准**：远壁下方处高出噪声底 ≥ 6 dB 的频率中，按分辨率表取最锐的一档；可接受集合与置信度沿用现有做法 | 远壁下方取多深的余量 | 与判据对照 |
| 深度 | D 组 | **改为以目标为准**：能盖住远壁 + 余量的最浅一档 | 远壁下方要留多少余量：由 R 帧里医生的选择分布标定 | 余量的来源 |
| 聚焦 | Z 组 | 目标深度处侧向斑点宽度最小的一档（现有聚焦判据限定到目标带） | — | 与判据对照 |

说明：

- 分辨率表（谐波每个显示深度下各档频率的点靶分辨率）是**探头的性质**，继续用体模点靶测量的那张表，人体上无法测点靶。
- 以目标为准之后，深度只看「盖不盖得住远壁」，频率只看「远壁处有没有余量」，两者不再读同一个图像底部量。体模上两轴曾互相推（深度加深 → 频率要降 → 穿透变深 → 深度再加深），改后这种耦合在规则层面就不存在；仍要用 `tests/verify_frontend_chain.py` 在人体数据上验证沿标签走一定停下。
- 以目标为准后，深度标签两个方向都会大量出现：浅血管上预设默认的 41.9 mm 是「太深」，颈内动脉、椎动脉上常是「太浅」。Field II 标签里「当前太深」只有 79 行（共 6048 行），网络几乎学不到减小深度，人体数据正好补上。
- 旧的与任务无关的判据照常生成一份标签，与新判据并列，比较两者在人体上的分歧。
- **专家设置不直接当标签**：医生之间本身有差异（§6.7 的双人对照量出来），直接学专家会学到某位医生的习惯。专家帧的作用是标定判据里的自由参数，以及作为验收时的对照。

## 12. 人体闭环实测（第二期，50 名测试受试者）

模型用第一期 250 人训练完成后，在第二期受试者的颈总动脉纵切与分叉部纵切（双侧）上，每个切面增加一个闭环块：

1. 恢复预设、不做调节，存一帧作为闭环起点；
2. 存一帧，运行 `tools_suggest_six_param.py`（需先完成本人的标定），得到六参数建议；
3. 操作者按建议调节（TGC 拖到大致位置即可，实际值从导出读），再存一帧；
4. 重复直到建议全部为「不动」或达到 6 步；
5. 最终帧与同一切面的医生 R 帧、闭环起点帧一起进入盲评（§10.2）与成对偏好比较。

报告：停下比例、步数、用时；最终图像与医生调优图像的偏好比较（胜 / 平 / 负）；内中膜厚度在三种图像上是否都可测量。

执行顺序与训练时的闭环一致：前端有改动时先改前端、重新存一帧，再做后端修正。

## 13. 数据管理

### 13.1 目录

```
data/hisense_invivo/
  CA0001_20261015/                 一名受试者 = 一个场次
    20261015093012345/             主机导出的采集目录（原样保留）
    ...
    log.csv                        记录员的切面时间表
  daily_qc/
    20261015/                      当天体模质控
  manifest.csv                     全部采集的清单（由脚本生成）
  subjects.csv                     受试者编号、分层、划分、身高体重颈围（不含姓名）
```

### 13.2 清单字段

`manifest.csv` 每行一帧：受试者编号、划分、侧别、切面代号、块代号（P / R / F / Z / D / B / N / Q / 闭环步）、块内序号、计划设置、实际设置（从 `.pdt` 读出）、成像模式、操作者、运动检查结果、曝光检查结果、标注状态。

**切面信息靠记录员的时间表对上主机时间戳**，不在屏幕上打文字注释：注释会画进图像区，污染截图标定。预实验可以试一下注释是否能放在图像区以外（`DICOM.pdt` 里记录了图像区的位置），能的话再改为注释。

### 13.3 存储与脱敏

- 每个采集目录约 11 MB：`Screenthum.bmp` 6 MB、DICOM 文件 4.5 MB、BC0 0.45 MB。**DICOM 文件的像素与 BMP 逐位相同**（`display_palette.py` 的注释），且它的文件头含受试者信息；确认头里没有研究需要的字段后，导出时删除 DICOM，每帧降到约 6.5 MB。
- 标准版 300 人约 10 万帧，约 650 GB；准备 2 TB 存储并异地备份。
- 受试者编号与真实身份的对照表单独保存在伦理要求的位置，不进入数据目录，不进 git。

## 16. 风险与未决问题

1. **标签判据在人体上可能需要重新定义。** §11 的「以目标为准」是提议，必须用预实验与第一个 50 人的数据检验：与医生盲评方向的一致率、沿标签走能否停下。
2. **TGC 目标的定义。** 人体组织分层使「各深度一样亮」不再成立；若偏好阅片显示医生的偏好差异很大，TGC 目标可能要按切面分别标定。
3. **医生之间的差异可能大于参数之间的差异。** 双人对照（§6.7）量出来之后，死区与可接受集合都要据此放宽，否则模型会被要求区分医生自己都分不出的差别。
4. **谐波成像没有仿真对应物。** 人体谐波数据只能靠体模与人体自身；Field II 预训练只能提供基波上的物理规律。
5. **谐波的频率跨度只有 1.30 倍（发射 4.4–5.7 MHz）**，体模点靶上 5.3 与 5.7 MHz 的分辨率相差不到 3%，可视为并列（实机训练数据分析 §1.2）。人体上频率标签会有较多并列档，以可接受集合为主。
6. **主机与探头在几个月里的变化。** 由每日体模质控监测；一旦升级或换探头，前后两段数据要能分开分析。
