# 六参数闭环：针对当前 Field II、海信数据与标签的模型推荐

日期：2026-09-14。本文给出基于当前数据可用性的模型选择与实验设计，未进行模型训练或性能对比，所列结构和超参数为待验证的起点。

## 1. 推荐结论

第一优先级是 **分层、有约束的闭环优化**：后端用平滑有界的 Gain/TGC 求解器，前端用实测指标驱动的离散候选搜索，DR 在明确显示目标后用一维离散搜索。学习模型负责提供快速初值或候选顺序，接受与回退仍依赖重新评价。

如果现在要选一个学习模型做首轮实验，优先 **物理统计特征 + 浅层 CatBoost**，分别学习有效轴的方向/修正量；与直接求解器、固定规则、常量预测比较。后端若需要利用深度分布的局部关系，可采用 **1D CNN + 参数分支**，参数量控制在小规模。

如果目标是最终论文中的图像驱动 AI 系统，第二阶段推荐 **小型图像编码器/ResNet-18 + 深度统计分支 + 当前参数分支，使用分任务输出与监督掩码**。先只训练 Gain/TGC，前端待标签与跨域判据得到验证后再增加头部。ResNet-18 是需要比较的候选，不是本数据已经证明最好的网络。

在线重采昂贵时，前端可以升级为 **离散 GP Bayesian Optimization（BO）**。不建议现在用 PPO/SAC/DQN 或大型 Transformer 同时控制全部参数；当前没有可信的完整六参数奖励和充分覆盖的状态转移。

## 3. 参数与算法逐项选择

| 参数 | 首选算法 | 学习模型的合理用途 | 主要原因 |
|---|---|---|---|
| Depth | 目标覆盖约束 + 合法档位枚举 | 预测目标范围/穿透置信区间，或少量条件方向分类 | 先明确看什么，再决定视野；不能靠亮度直接决定 |
| Frequency | 同 ROI 的质量向量比较 + 离散搜索；昂贵重采时用 GP-BO | 候选排序/响应预测 | 高频的穿透代价明确，但实际分辨率收益需验证 |
| Focus | ROI 加权的离散邻域搜索 | 预测有希望的焦点区间或排序 | 不应把整幅图的中段焦点等同于任意目标最优焦点 |
| Gain | 固定 TGC/DR 后的一维有界搜索 | CatBoost 回归或小网络预测初值 | 执行模型简单，通常不需要复杂策略网络 |
| TGC | 带组织权重、平滑正则与执行器边界的拟合 | 1D CNN/MLP 预测形状，再投影到可执行集合 | 深度结构强；只预测 near/mid/far 会丢失八滑块细节 |
| DR | 定义显示约束后的离散一维搜索 | 将来用偏好排序或可见性预测模型 | 当前没有 DR 监督，换网络不能补出缺失的目标定义 |

“六参数”实际含八个 TGC 滑块：3 个前端 + 1 Gain + 8 TGC + 1 DR，共 13 个数值控制量。模式作为上下文，第一版固定，不混入额外搜索。

## 4. 第一版：先建立可靠的算法基线

### 4.1 后端优化

在固定前端、同一 envelope/BC0 上，求：

\[
\min_{G,t,DR} J_{display}(R(L;G,t,DR)) + \lambda\|D_2t\|^2.
\]

J 至少包括有效组织的裁剪、目标亮度区间、同类背景均匀性与低信号区过度提亮。ROI、组织权重与有效性在一次搜索中保持固定。目标/声影内本来应暗的区域不强制补亮。

推荐实现次序：

1. 从原始信号域生成带置信度的组织掩膜，提取 32–64 个深度采样位置的稳健组织电平。
2. 用有界平滑拟合求 TGC，采用实际滑块基函数；固定其 ROI 加权平均补偿为零，把整体亮度交给 Gain。
3. 对 Gain 做粗到细的一维搜索，或对少数 TGC 形状强度候选分别搜索 Gain。
4. 初版保留当前 DR。定义好 DR 的任务后，枚举实际可设置的 DR，对每个 DR 重新求 Gain/TGC，避免将三者完全解耦造成偏差。
5. 量化到真实档位后重新渲染与评分，不能仅验证连续解。

固定 DR 时，有界最小二乘/二次规划能解决一类 TGC 近似问题；完整显示代价含阈值、分位数与裁剪，不保证全局凸，宜采用分块求解与枚举，不宣称一次凸优化解决全问题。

当前 `backend_solver.py` 已具有部分基础，无需先重新搭建复杂网络。神经网络应在教师正确、计算开销确实需要降低时作为加速器。

### 4.2 前端优化

对前端 a=(D,f,zF)，先把其观测做后端调优，再比较：

\[
Q(a)=Q_{acq}(L_a;ROI)+\eta Q_{display}(R(L_a,b^*(a)))-\beta C_{acq}(a).
\]

Qacq 是目标覆盖、分辨率、穿透/可分辨性等指标，不能仅用后端 objective 代替。Cacq 包含帧率或重采开销。量纲归一化与权重在训练/验证组确定，并保留各分量，必要时先按硬约束筛选，再比较质量，不强行用一个总分掩盖失败。

离线先对已采候选做穷举，建立该集合的参考最优；再比较相同查询预算下的邻域搜索与 BO。未采候选只可作为代理预测，不能向离线回放器返回虚构观测。

不是先独立求 D/f/focus 三个最佳值再同时执行：标签是条件建议，改一轴后其他两轴的条件改变。控制器应重新观测、重新评分，或在有足够联合候选时采用小范围块搜索。

### 4.3 GP-BO 什么时候值得用

GP 用已采 `(a,Q)` 拟合均值与不确定性，在合法离散动作上用 EI/UCB 一类采集函数选下一候选。三维、少量昂贵采集适合将普通 GP-BO 作为候选；第一版不需要训练深核。可从标准化输入、Matérn 核和观测噪声项起步，模式分开拟合。

其前提是 Q 已定义且有可接受的测量重复性。数据中不连续的模式/预设响应需分组或合适核函数；方差不是自动校准的安全保证。

BO 用于昂贵黑箱目标是成熟思路，见 [Snoek 等原论文](https://proceedings.neurips.cc/paper_files/paper/2012/hash/05311655a15b75fab86956663e1819cd-Abstract.html)。超声中的相关研究也采用 CNN 质量反馈与 BO，但 [Raina 等](https://arxiv.org/abs/2310.07392) 优化的是机器人探头控制，不能把其结果直接当作这六个旋钮的验证。将 GP-BO 用于本项目是基于问题结构的建议，仍需与简单搜索比较。

## 5. 首个学习基线：物理特征 + CatBoost

### 5.1 为什么先选它

现有前端只有几十个比较集，直接从图像中学习所有组织与成像特征很容易过拟合。可以先用少量物理统计特征压低模型复杂度，测试弱标签是否可学习、跨场次是否一致。

树模型在表格学习中是必要基线，已有对照研究支持这一点；这不是对超声数据上胜过 CNN 的保证，见 [Shwartz-Ziv 与 Armon](https://arxiv.org/abs/2106.03253)。选择 CatBoost 是便于混合数值特征与模式类别、开展浅树回归/分类实验；XGBoost 或 Random Forest 可作对照，不必同时堆进系统。

### 5.2 输入与输出

建议输入：

- 当前 D、f、focus、Gain、8 TGC、DR，以及 mode。
- 每个深度带的原始 dB 分位数、趋势斜率、有效组织比例和噪声间隔。
- 当前渲染图的裁剪比例、组织灰阶分布。
- 有可信 ROI 时，加入目标位置、目标/背景对比和经验证的宽度指标；没有则提供缺失标志。
- 物理坐标、有效视野、标定置信信息；不输入 frame_id、session_id 或生成器的 optimal、basis 等答案信息。

初版输出：Gain 修正量、TGC 形状的少数系数或八维修正量，以及三个前端轴的方向概率。每根轴分别训练/屏蔽，DR 不建立监督头。TGC 多输出也可通过少量独立回归器实现，然后统一做约束投影。

建议从树深 3–5、少量特征、组内均衡权重和早停开始；这些只是初始搜索范围。由于特征可能已足以直接复现教师规则，必须比较“原规则/求解器”与树模型；若模型不提高速度、鲁棒性或任务表现，就不必部署它。

已有方向伪标签只支持方向预测。要做候选 Ranker，应重新获得同一比较集各候选的质量值或可靠偏好对，不可将 current 设置字段当作偏好标签。CatBoost 提供分组排序目标，具体见 [官方排序目标文档](https://catboost.ai/docs/en/concepts/loss-functions-ranking)。

## 6. 图像模型推荐：分阶段增加，而非一次训练六头

### 6.1 适合后端的最小网络

先用 **深度统计 1D CNN + 当前参数 MLP**。例如 64 个深度位置，每位置若干个分位数/组织比例/置信度；经两到三层一维卷积后与参数特征融合，预测 Gain 与 TGC。

这个网络利用 TGC 随深度缓慢变化的结构，可以比二维图像网络更省样本。它看不到充分的横向目标信息，因此针对囊肿、点靶与复杂声影需要保留外部掩膜/质量保护；如果此限制成为瓶颈，再加入图像分支。

### 6.2 更完整的研究模型

```text
原始 dB 图 + 有效视野/组织置信度 ─→ 小型二维 CNN 或 ResNet-18 ┐
深度统计序列 ─────────────────→ 1D CNN                     ├→ 融合特征
当前参数 + mode + 物理尺度/ROI ─→ 小型 MLP                   ┘
                                     ├→ Gain/TGC 建议
                                     ├→ Depth/Frequency/Focus 条件建议（后续）
                                     └→ 有效性/拒绝输出机制
```

ResNet-18 的残差结构可参考 [原论文](https://arxiv.org/abs/1512.03385)，但 ImageNet 权重是否有益须与从仿真训练的小 CNN 比较。只看 60 个仿真体模就使用大型主干并全量实机微调，容易记住体模纹理。

推荐 Field II 上先学习后端曝光、深度趋势与结构特征，海信微调时先冻结图像主干，只调整少量后端层。模式使用独立小输出头或条件分支；能否共享特征需用跨模式消融验证，不应先假设 THI 与 GEN 完全同域。

前端学习可以复用经验证的结构编码器，但当前 Field II JSONL 无前端标签，且 Depth 是最大深度仿真的裁剪重采样，频率穿透权衡缺少电子噪声。不能据此声称现在已经有完整三轴仿真监督。

### 6.3 两个必须处理的输入一致性问题

**BC0/envelope 对可控后端设置不敏感。** 同一原始观测可以对应不同当前 Gain/TGC，因此如果模型输出 delta，必须输入当前参数；或者预测绝对建议，再与当前设置相减。只喂原始 BC0 却要求识别当前 Gain 太高/太低是不可辨识的。

**Field II 标签的当前后端设置是生成器抽样得到的。** 若输入 B-mode，必须从 `/envelope` 按标签记录的 Gain/TGC/DR 渲染，而不是随便加载已有 preview 或 `/algo_bc0`。训练时重新抽取起点，应同步重算 delta 与方向/死区判定。

原始幅度与归一化图可同时输入：归一化有助于纹理识别，但其去掉的参考偏移必须保留，否则 Gain/穿透信息会丢失。仿真当前采用逐帧 tissue_median_db 作为显示参考，应明确这是一种归一化操作约定，不能把其 absolute optimal_gain_db 与实机场次绝对数值直接当成同一基准。

## 7. 损失函数和标签使用

对参数任务 a 使用有效性掩码 m 和经验证的置信权重 w：

\[
L=\sum_a\lambda_a\frac{\sum_i m_{ia}w_{ia}L_a(i)}{\sum_i m_{ia}w_{ia}+\epsilon}
+\lambda_s L_{TGC\ smooth}+\lambda_q L_{render}.
\]

- Gain：以 dB 为单位的 Huber，死区内可不惩罚，或到近优集合的距离；不要只追逐教师的小数点。
- TGC：优先在插值后的补偿曲线域以 dB 比较，再加平滑和零均值/基准约束；组方向作为辅助任务。
- 前端方向：带类别/比较集权重的交叉熵；未确定与低置信度不作为 correct。
- 前端候选：有独立测量偏好时可使用 pairwise logistic loss；不能仅以相同规则生成的关系再宣称独立验证。
- DR：当前 m=0；没有有效标签的任务不参与损失。

`label_uncertainty` 是目标函数单位，不是 dB；不能直接从 Gain dB 误差中减去它。若要构造 dB 容忍区间，使用 deadband_gain_levels×gain_db_per_level，或重新保存候选等效范围。

`objective` 是教师求解后的代价值，不是当前截图的专家质量分。不能直接训练 `当前图像 → objective` 并称其为当前图像 IQA；如需 IQA，应对实际输入图像按固定口径重新评分，标明评分是否依赖当前任务与 ROI。

小重复帧的教师解方差只表示重复性，不代表不存在系统标定偏差或规则偏差。低 label_uncertainty 也不等于临床最优可信。

## 8. DR 的完整处理路线

当前可以实现 DR 控制器，但不能用现有占位标签训练“最佳 DR 网络”。需先明确 DR 要优化的显示任务。

可选路线：

1. **工程显示目标**：固定组织/目标 ROI，限制有效组织裁剪，要求目标保留可见性与组织灰阶范围，再在少量合法 DR 档间搜索。阈值由验证集/使用偏好确定。
2. **偏好监督**：同一原始观测用多组 Gain/TGC/DR 渲染，由操作者盲选或做平局判断；训练小型 pairwise Ranker，用排序分驱动搜索。
3. **任务监督**：增加低对比靶或已知结构，使用固定观察者/检测任务评价渲染后的可见性，同时以未参与优化的指标验证。

gCNR 对共同可逆单调变换具有理想不变性，因此仅靠它难以选显示窗宽；裁剪和量化虽会改变指标，也不能保证存在符合使用偏好的唯一最优。无需等待像素级理想图 GT，但必须补充目标定义或偏好信息。

第一版保留当前 DR 并显式说明 DR 尚未自动优化；只有增加上述独立选择准则并完成验证后，才可宣称实现完整六参数闭环。

## 9. 暂不优先的方案

| 方案 | 当前不足 | 何时再考虑 |
|---|---|---|
| PPO/SAC/DQN 六参数联合 RL | 前端动作支持稀疏、DR 奖励未定、交互转移不足；离线拼接可能创造错误环境 | 有可信模拟环境/大量轨迹与独立奖励验证后 |
| 直接 ResNet/ViT 一次输出六参数 | 标签缺失、条件建议不等于联合最佳、真实场景少 | 先验证分层系统，再与端到端模型比较 |
| GAN/diffusion 生成“好图”再反推参数 | 生成的理想外观未必能由硬件旋钮实现，也不是理想图 GT | 确有额外重建任务与独立依据时 |
| 将自然图像 IQA 分数直接作为超声奖励 | 对斑点、无回声区与医学目标的偏好未验证 | 获得域内校准与任务一致性证据后 |
| 立即引入复杂深核 BO | 普通 GP 的三维前端模型尚未建立，数据不足以证明深核收益 | 简单 BO 的容量或迁移确实成为瓶颈时 |

## 10. 推荐的实验顺序与验收

**阶段 A：先建立可比较基线。** 修复组织掩膜域、模式 TGC 系数、硬件步数映射，统一数据/标定/标签版本；固定 DR，建立可靠 Gain/TGC 求解与前端有限候选回放。当前代码中这些已知问题仍存在，本次未修改。

**阶段 B：验证后端学习收益。** 比较保持当前值、确定性求解器、CatBoost、1D CNN；必要时再加小型二维 CNN。用 Field II 训练，用海信做分组微调和验证。已有多后端起点的真实采集用于检验扰动渲染是否可信，不以合成自洽代替实机保真。

**阶段 C：前端模型与搜索。** 先验证频率质量前提，构建同 ROI 的候选质量；比较有限预算随机、邻域搜索、GP-BO与学习初始化。项目最新实机报告指出散斑宽度没有稳定支持“高频必然更好”，但接近采样极限，不能直接判定真实点靶分辨率变差；必须用点靶或目标任务测量进一步判断。

**阶段 D：补 DR 目标后接入。** 优先枚举/排序，不为一维窗宽控制先训练大型模型。

数据划分：仿真按 seed/体模，实机优先按场次或经验证独立的物理位置整组划分；同场次不同模式不能仅因 family_id 加模式后就被拆进不同集合。前端样本少，采用留一场次/场景的外层交叉验证，有监督的折单独报告；超参数在内部组划分调，避免用外层测试折选择模型。轮流留出不能创造新的独立体模，泛化结论仍限于当前数据。

指标：方向 macro-F1、有效任务覆盖率、Gain dB/补偿曲线误差、可执行边界比例、近优集合命中率、闭环步数、实际延迟、同采集预算的目标质量和有限网格 regret。至少一个目标质量指标不参与教师优化；对场景进行统计，而不是把同一 BC0 的大量扰动当独立样本。

只有当学习模型在未见场次达到接近教师的任务质量，并实测降低延迟或采集次数，才有部署价值。若确定性求解器本身已足够快且可靠，保留它就是合理的工程选择。

## 11. 最终选型建议

当前实施组合：**有界平滑 Gain/TGC 优化 + 前端离散质量搜索 + 明确目标后的 DR 枚举**；学习基线先选 **CatBoost / 后端 1D CNN**。

研究扩展组合：**小型多任务图像/深度特征模型提供建议 + 确定性后端校正 + GP-BO 选择昂贵的前端查询 + 每步质量验证与回退**。

这些组合直接利用现有 envelope/BC0 和部分弱标签，能够逐项验证收益。当前证据支持开始后端学习与前端基线实验，尚不足以选定一款已证实最优的完整六参数网络。
