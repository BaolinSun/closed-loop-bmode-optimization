# 人体心脏数据采集方案 —— 六参数闭环优化的扩展（v1）

日期：2026-09-28。主机：海信。规模：约 300 名受试者。**只使用谐波成像。**

用途：把 **深度、频率、聚焦、增益、TGC（时间增益补偿）、动态范围** 六参数闭环从颈动脉扩展到经胸心脏超声。本方案与颈动脉方案 [carotid_invivo_acquisition_protocol.md](carotid_invivo_acquisition_protocol.md)（下称「颈动脉方案」）同步进行，受试者管理、质控框架、偏好阅片、数据管理与之共用，本文只把共用部分简要引用，重点写心脏不同的地方。所引数字来自体模协议 [phantom_acquisition_protocol_v4.md](phantom_acquisition_protocol_v4.md)、网络文档 [six_parameter_network_20260915.md](six_parameter_network_20260915.md) 与 `runs/` 下的训练结果。

---

## 0. 一页摘要

| 决定 | 内容 | 章节 |
|---|---|---|
| **心脏不是颈动脉的延伸，而是一个新的域** | 探头（相控阵扇扫）、几何（扇形）、深度（到 20 cm 以上）、运动（心跳、呼吸）全变了；现有的档位表、执行器常数、分辨率表、噪声底、标定、读取代码**一项都不能直接沿用** | §2 |
| **先做三件阻塞项，再采人** | ① 心电门控与电影多帧导出能否用（决定能不能做前端比较）；② 心脏探头在体模上的标定（对应颈动脉体模的 E0–E9）；③ 读取与标定代码支持扇形几何 | §3 |
| 采什么 | 与颈动脉相同的采集块：预设起点帧、专家调优帧、频率 / 聚焦 / 深度三组扫描、后端阶梯；**每一帧都取舒张末期**，扫描在呼气末屏气中完成 | §8 |
| 切面 | 核心 5 个：胸骨旁左室长轴、胸骨旁短轴（乳头肌水平）、心尖四腔、心尖两腔、剑突下四腔；建议加 2 个：心尖三腔、胸骨旁短轴（主动脉瓣水平） | §6 |
| 受试者 | 300 人：约 40% 健康志愿者、约 60% 心脏超声室的患者（心腔扩大、室壁肥厚、射血分数减低、瓣膜病）；**至少 20% 为成像困难者**（肥胖、肺气肿） | §5 |
| 心脏特有的质量判据 | 医生逐帧评「左室心内膜清晰显示的节段数」——这是颈动脉没有的、**与标签规则无关的临床质量量尺**，用来裁决前端标签 | §12.2 |
| 动态范围 | 与颈动脉一样靠离线成对偏好阅片，由心脏超声医生阅 | §12.3 |
| 每人时长 | 约 45 分钟，约 150 次存储（每次若为电影则含多帧） | §9 |

## 1. 术语与简写

| 简写 | 全称 | 含义 |
|---|---|---|
| TGC | Time Gain Compensation | 时间增益补偿，8 个滑块，只能拖到大致位置 |
| LGC | Lateral Gain Compensation | 侧向增益补偿，按扫描线方向（左右）施加的增益；**不属于六参数，全程关闭** |
| DR | Dynamic Range | 动态范围；界面数字不一定是 dB，心脏预设须重新标定 |
| BC0 | `Algo_BC0.bin` | 增益、TGC、动态范围之前的对数域包络扫描线数据 |
| 谐波成像 | 组织谐波成像（`BImageMode` = 1） | 发射 f、接收 2f |
| ECG | Electrocardiogram | 心电图 |
| ED / ES | End-Diastole / End-Systole | 舒张末期 / 收缩末期。舒张末期取心电 R 波顶点或二尖瓣关闭前一帧 |
| EF | Ejection Fraction | 左室射血分数 |
| MI / TI | Mechanical Index / Thermal Index | 机械指数 / 热指数，声输出安全指标 |
| 切面简称 | 胸骨旁长轴、胸骨旁短轴、心尖四腔、心尖两腔、心尖三腔、剑突下四腔 | 见 §6 |

采集块代号与颈动脉方案相同：**P** 预设起点帧、**R** 专家调优帧、**F** 频率扫描、**Z** 聚焦扫描、**D** 深度扫描、**B** 后端阶梯、**N** 噪声底帧、**Q** 复位复现帧。

## 2. 心脏与颈动脉的根本差异

| 项 | 颈动脉（已有工作） | 心脏 | 对本任务的后果 |
|---|---|---|---|
| 探头 | L15-4 线阵 | 相控阵（扇扫），型号待确认 | 频率、深度、聚焦档位全部重新读取 |
| 几何 | 矩形，每条扫描线间距固定（0.149 mm） | 扇形，扫描线是角度，横向间距随深度增大 | 读取代码目前按 `宽度 / 线数` 算线距，**扇形下是错的**；聚焦判据的「侧向斑点宽度」必须换算成毫米 |
| 深度 | 25–75 mm | 常用 140–200 mm，剑突下可到 240 mm | 穿透与频率的取舍远比颈动脉尖锐；噪声底在大多数帧的底部都可见 |
| 成像模式 | 谐波 + 基波 | **只用谐波** | 频率只有谐波一条档位轴；Field II 没有谐波，仿真预训练与心脏的域差更大 |
| 运动 | 血管搏动，幅度约 1 mm | 心腔整体收缩舒张、瓣膜开闭、呼吸带动心脏移位 | **不同时相的两帧不是同一个场景**。不做心电门控，前端比较集就不成立 |
| 声窗 | 颈部表浅，几乎总有好声窗 | 肋间、心尖、剑突下；肺和肋骨遮挡 | 成像困难者多，这正是闭环优化最有价值的人群 |
| 目标 | 血管远壁 | 左室心内膜、瓣膜、心房 | 质量有公认的临床量尺（心内膜显示节段数） |
| 帧率 | 不是问题（历史帧 43 帧/秒） | 临床关注，深度越深帧率越低 | 「深度不要多余」有了第二个理由；记录 `FRS` |
| 无回声区 | 血管腔 | 心腔血池（面积大，谐波下仍有杂波） | 后端组织掩膜必须去掉血池，否则增益会把血池提亮 |
| 近场 | 皮下层次 | 心尖切面的近场混响杂波 | 近场杂波不应被 TGC 当成组织去补偿 |

**结论：心脏数据不能直接并入现有训练集，必须当作新域，先在体模上建立档位与标定，再采人体。**

## 3. 阻塞项：采人之前必须完成

### 3.1 心电门控与电影导出（决定方案能否执行）

在体模和 1–2 名志愿者身上确认：

| 项 | 怎么查 | 若不行 |
|---|---|---|
| 主机有心电模块、屏幕显示心电波形 | 接三导联 | **心脏前端扫描无法做**：不同时相的帧不可比较，只能采后端数据（每帧自带标签的增益、TGC）与专家帧 |
| 存储电影回放时 BC0 是否为多帧 | 看 `Algo_PartitionInfo.pdt` 的 `PageNum` 是否大于 1、文件大小是否等于 `PageSize × PageNum` | 冻结后把电影回放拨到舒张末期再存单帧；需确认存下的 BC0 是当前显示帧而不是最后一帧 |
| 多帧导出时每帧的心电时刻 | 查导出文件中是否有逐帧时间戳或心电数据 | 用帧率与 R 波标记推算 |
| 冻结后改前端参数 | 不可能（前端参数改变要重新发射） | —— 这就是每改一次前端都要重新存一帧的原因 |

**首选方案：每次存储 2–3 个心动周期的电影**，离线按心电挑舒张末期与收缩末期帧。这样同一设置有多个心动周期可平均，比较集的噪声大大减小。读取代码目前假设单页（`load_bc0` 把整个文件按一页重排），多帧需改（§3.3）。

### 3.2 心脏探头的体模标定（对应颈动脉体模协议的 E0–E9）

颈动脉侧用了 18 个场次、420 多帧体模数据才把档位与常数定下来。心脏预设要重做以下各项，但可以直接用已经走通的方法，预计 3–5 个工作日：

| 编号 | 内容 | 对应颈动脉 | 产出 |
|---|---|---|---|
| C0 | 读出全部档位：谐波频率各档的发射频率（`BFreqValue`）、深度阶梯、聚焦阶梯与上限规则、扇形角度 | E0、§7.2 | 档位表；确认只有单焦点（`BFocusNumValue` = 1），多焦点预设要关掉 |
| C1 | 增益、TGC 的每级 dB | E3、E6、E7 | 执行器常数 |
| C2 | 动态范围界面数字与有效窗宽的关系 | E5 | 窗宽公式（颈动脉为 0.352 × 界面数字 + 35.1，心脏预设**必须重测**，不能借） |
| C3 | 深度响应修正 C(z) | S0、E1 | 每种频率的深度响应 |
| C4 | 噪声底随频率：最大深度、各档频率，探头在体模上与离体空载各一组 | E8 | 噪声底；空载与体模深部是否一致 |
| C5 | 点靶分辨率表：各档频率在各显示深度下的轴向、侧向半高全宽 | 点靶验证 | 频率判据用的分辨率表 |
| C6 | 聚焦：点靶在不同聚焦下的侧向宽度 | E9 | 确认聚焦是一根干净的轴 |
| C7 | 复现：同一位置重复、移动探头后重复 | §7.9 | 漂移与复现误差 |

**需要一个深的体模**：C4、C5 需要显示深度到 200 mm 以上仍有均匀散射背景，且在 20–180 mm 之间分布线靶。颈动脉用的体模深度未必够，须先确认；不够就要借或购一个通用深部体模。

### 3.3 代码改造

| 项 | 现状 | 要做 |
|---|---|---|
| 扇形几何 | `Geometry.mm_per_line` = 扫描宽度 / 线数，只对线阵成立 | 读 `ProbeType`、`ScanMode` 与扇形角度（`BTotalScanWidthBack` 在线阵帧上是 1.047198，即 60°，需在心脏帧上核实含义），给出每条线的角度与每个深度的横向间距 |
| 截图对照 | 标定与调色板反解用 `scan_convert_linear` | 增加扇形扫描变换，否则每人的标定无法拟合 |
| 多帧 BC0 | `load_bc0` 只按一页重排 | 支持 `PageNum` > 1，并附每帧时刻 |
| 聚焦判据 | 侧向斑点宽度以线数计 | 换算为毫米（角度 × 深度） |
| 网络 | 前端三个头的档位数按颈动脉定 | 按 C0 的档位表重设输出层，其余部分装入颈动脉模型（与实机微调相同的部分装入） |

## 4. 已有训练结果对心脏的含义

| 已有结果 | 对心脏的含义 |
|---|---|
| 实机微调：频率方向 F1 0.47，不如只看设置的查表 0.70；实机全部来自一个体模，不看图能猜中 95% 的频率方向 | 场景多样性是第一需要。心脏受试者之间的差异（体型、心腔大小、声窗）远大于颈动脉，只要比较集成立，这一点天然满足 |
| Field II 最终模型：深度 top-1 准确率 0.54，是三个前端轴里最弱的；Field II 标签里「当前太深」只有 79 / 6048 行 | 心脏上深度是最重要的一轴（帧率、穿透、目标完整性都取决于它）。本方案的深度扫描两侧都采，且规则改为以目标为准（§13），两个方向都会大量出现 |
| 增益正反馈：`fieldii_v4` 用按数据标准化的标量训练，预测最优增益对当前增益的斜率 1.45，闭环发散；改用 `levels` 后斜率约 0 | 心脏是新的 dB 刻度，微调必须用 `--scalar-norm levels`，并在心脏验证集上检查斜率 < 0.5 |
| 闭环：打转冻结是唯一起作用的防护，Field II 测试集 96% 停下 | 闭环逻辑可直接沿用；心脏上要重新验证停下比例 |
| 动态范围两个数据源都没有判据 | 心脏同样只能靠偏好阅片 |
| 谐波成像没有仿真对应物 | 心脏只用谐波，训练链路里离心脏最近的是**颈动脉人体的谐波数据**（§14） |

## 5. 受试者

### 5.1 构成与分层

| 组 | 人数 | 说明 |
|---|---|---|
| 健康志愿者 | 约 120 | 按年龄 18–39 / 40–59 / ≥ 60 岁 × 体重指数 < 24 / 24–28 / ≥ 28 分层，男女各半 |
| 心脏超声室患者 | 约 180 | 从临床检查的患者中招募，覆盖：左室扩大（扩张型心肌病、缺血性心肌病）、室壁肥厚（高血压、肥厚型心肌病）、射血分数减低或节段性室壁运动异常、瓣膜病、心房扩大 |

在此之上的两个配额（与上表交叉计数）：

- **成像困难者 ≥ 60 人（20%）**：体重指数 ≥ 30、慢性阻塞性肺病或肺气肿、胸廓畸形、术后胸壁。这些人最需要参数优化，也最容易让判据失效；普通招募会偏向容易成像的人，要主动招。
- **心房颤动 ≤ 30 人（10%）**：心动周期不规则，舒张末期的心腔大小逐搏变化，比较集噪声更大。纳入是为了贴近临床，但在分析中单独标记。

心腔大小决定所需深度，这正是深度这一轴最需要的多样性：扩张心脏需要更深的显示深度，小心脏过深就浪费帧率与分辨率。

### 5.2 纳入与排除

- 纳入：18 岁以上，能左侧卧位与平卧各 20 分钟，能配合平静呼吸（屏气不是必须，见 §8.4）。
- 排除：血流动力学不稳定、急性冠脉综合征急性期、胸前区伤口或敷料、不能左侧卧、使用造影剂当天。
- 起搏器、人工瓣膜：可纳入，单独标记（金属伪影与声影）。

### 5.3 伦理与安全

- 伦理批准与知情同意，同颈动脉方案 §3.3。研究性采集不出报告；发现未知的严重异常按伦理方案告知。
- 声输出：使用心脏预设的声功率，不超过预设上限；记录每帧的机械指数与热指数；每人扫查时间不超过 45 分钟。
- 屏气：每次不超过 10 秒，两次之间至少休息 3 次平静呼吸；呼吸困难者不要求屏气。
- 左侧卧位对老年、心衰患者可能不适，随时允许中断。

### 5.4 划分

按人事先划分 **训练 200 / 验证 50 / 测试 50**，在每个分层与患者类别内随机；两期采集，第二期 50 名测试者在模型训练完成后采，并做人体闭环实测（§15）。

**若有受试者同时参加颈动脉与心脏两项采集，两个数据集里此人必须落在同一集合**，否则将来训练同时用两个数据集的模型时，同一个人会同时出现在训练与测试里。招募时统一分配受试者编号与划分。

## 6. 切面

### 6.1 核心切面（每人必采）

| 切面 | 体位 | 常见显示深度 | 远端目标 | 对六参数的主要作用 |
|---|---|---|---|---|
| **胸骨旁左室长轴** | 左侧卧 | 140–160 mm | 左室后壁、心包，其后的降主动脉 | 目标层次分明（右室前壁、室间隔、左室后壁）；近场右室前壁常被杂波盖住，检验近段 TGC；降主动脉给深度一个解剖锚点 |
| **胸骨旁短轴（乳头肌水平）** | 左侧卧 | 140–160 mm | 左室下壁、心包 | 左室呈环形，心内膜一圈都要看清，**侧向分辨率与聚焦最敏感**；环形两侧的侧壁常因声束方向显示差 |
| **心尖四腔** | 左侧卧 | 160–180 mm | 左右心房顶 | **穿透与频率取舍的主力**：心尖在近场、心房在远场；近场杂波、侧壁回声失落都在这里出现 |
| **心尖两腔** | 左侧卧 | 160–180 mm | 左心房顶 | 左室前壁常被肺遮挡，考验增益与 TGC 在回声失落时不要乱补 |
| **剑突下四腔** | 平卧屈膝 | 180–240 mm | 心房、对侧心腔 | 最深；声束先穿过肝脏，**肝实质是人体上最均匀的组织**，是增益 / TGC 的干净参照；成像困难者（肺气肿）常只有这个声窗 |

### 6.2 建议增加

| 切面 | 为什么 |
|---|---|
| **心尖三腔（心尖左室长轴）** | 补全心尖切面的左室节段；与心尖四腔、两腔合起来覆盖全部 17 节段中的心尖视角 |
| **胸骨旁短轴（主动脉瓣水平）** | 目标浅（主动脉瓣约 60–90 mm）而显示深度常被设深，最可能产生「当前太深」的标签 |

### 6.3 可选

| 切面 | 用途 |
|---|---|
| 剑突下下腔静脉长轴 | 肝脏背景下的管状无回声结构，与颈动脉纵切形态相近，可用来检验两个域的迁移 |
| 心尖五腔 | 与心尖四腔相近，只在时间充裕时采 |

### 6.4 不采的内容

彩色多普勒、频谱多普勒、组织多普勒、M 型、造影、局部放大、双幅显示——都会改变处理链或几何。**扇形宽度保持预设默认，不作调节**：它影响帧率，但不属于六参数，改了会让同一切面的帧之间几何不同。

## 7. 主机设置

### 7.1 固定

原则与颈动脉方案 §5.1 相同：C0 阶段把心脏预设的全部后端设置逐项抄下（灰阶曲线、色调、边缘增强、斑点抑制、平滑、帧相关、空间复合、线密度、扇形宽度、偏转、声速、声功率等），研究期间一律不动，每天开机核对，检查脚本逐帧从 `.pdt` 核对。特别强调：

| 项 | 应为 | 原因 |
|---|---|---|
| 成像模式 | **谐波成像** | 本方案只用谐波 |
| 自动优化 | 关 | 开着主机会自己改增益 |
| 侧向增益补偿 | 关（或全部居中） | 心脏检查常用它补侧壁，但它不属于六参数；开着会让「增益 / TGC 的最优」混入它的作用 |
| 发射焦点个数 | 1 | 多焦点时「聚焦往哪调」的含义不同 |
| 色调、灰阶曲线 | C0 抄下的值 | 截图反解灰阶依赖它们 |
| 帧相关（时间平均） | C0 抄下的值 | 心脏预设通常开着；它把相邻帧平均，影响舒张末期帧的清晰度，必须固定 |
| 心电 | 接上，屏幕显示 | 门控 |

### 7.2 六个参数

深度、频率（谐波各档）、聚焦的档位由 C0 读出后填入本表；增益、TGC、动态范围的每级 dB 由 C1、C2 定出。**在 C0 完成之前，本方案里所有「几档」「几 mm」都以 C0 的实测为准。**

## 8. 每个切面的采集流程

### 8.1 采集块

结构与颈动脉相同，只有扫描范围按心脏定：

| 块 | 帧数 | 做什么 |
|---|---|---|
| **P** | 1 | 恢复心脏预设默认，存一次 |
| **R** | 1 | 医生按临床习惯调好六个参数，存一次 |
| **F** 频率 | 全部谐波档减 1，加回 R 1 次 | 深度、聚焦保持 R，逐档存 |
| **Z** 聚焦 | 5 + 1 | 深度、频率保持 R；聚焦从 40 mm 到「显示深度 − 10 mm」大致等分取 5 档（取最近的主机档位），不含 R；最后回 R |
| **D** 深度 | 5 + 1 | 频率、聚焦保持 R；取 R 的深度 −40、−20、+20、+40 mm（取最近的主机档位）和**主机最大深度**；最后回 R |

设谐波有 5 档频率，一个完整块 = 1 + 1 + 5 + 6 + 6 = **19 次存储**。

深度扫描的四档要保证：**至少一档切掉了远端目标**（心尖切面切掉心房顶），**至少一档在目标下方留出大片空白**。若 R 离主机的深度上下限太近，缺的档向另一侧补。最大深度那一档兼作噪声底帧。

### 8.2 每一次存储都取舒张末期

- **首选**：存 2–3 个心动周期的电影，离线按心电挑舒张末期（并同时得到收缩末期）。
- **不能存多帧时**：冻结，把电影回放拨到心电 R 波处（舒张末期）再存。
- 前端比较集只在**同一时相**的帧之间比较。收缩末期的帧可作为第二套比较集，检验标签是否随时相变化。

### 8.3 运动检查

一个完整块内的 4 次 R（开头 1 次、每组扫描结束各 1 次）设置相同、时相相同，只差呼吸与探头运动。判据用空间结构：舒张末期帧的归一化互相关，以及二尖瓣环两点、室间隔的位置偏移。阈值由预实验定；心脏的逐搏与呼吸变化大于颈动脉，预计重采率更高，预实验要量出来（§17）。

### 8.4 呼吸

- 每组扫描（5–6 次存储）在 1–2 次呼气末屏气中完成，每次屏气不超过 10 秒。
- 胸骨旁与心尖切面在呼气末声窗通常最好；剑突下切面常在深吸气末最好——由医生按声窗决定屏气时相，**同一组扫描内保持同一个时相**。
- 不能屏气者：平静呼吸，在呼气末存储，并在记录里标注。

### 8.5 后端阶梯 B

在胸骨旁长轴与心尖四腔的 R 之后各采一组，5 次存储：增益约 −3 dB、增益约 +5 dB、TGC 平档（用预设曲线里的竖直线）、动态范围两档（C2 标定后选取窄、宽各一档）。每级对应多少 dB 由 C1 给出后换算成旋钮级数。

作用与颈动脉相同：每人一份自己的标定（不能借用；借用会让增益建议顶到限幅），并检验在心脏组织上后端重渲染是否可信。B 块内 BC0 不变（同一时相），同时是运动检查。

### 8.6 噪声底帧 N

心脏显示深度大，D 扫描的最大深度帧底部多半已是噪声（心尖切面心房之后、剑突下对侧之后）。仍保留一组**离体空载**：受试者开始前，探头擦净朝上，最大深度，谐波各档频率各存一次。C4 若证明空载与体模深部一致，改为每天一次，并入 §10 的每日质控。

### 8.7 复位复现 Q 与双人对照

- **Q（每人）**：心尖四腔结束后探头离开，重新找到切面，保持 R 的设置存一次；医生重新调到满意再存一次。心尖四腔是最难重复找到同一切面的，量出来的波动是心脏标签噪声的下限。
- **双人对照（30 人）**：第二名医生在胸骨旁长轴与心尖四腔上独立调到满意，各存一次 R。

## 12. 标注与阅片

### 12.1 解剖标注（每个完整块的舒张末期 R 帧）

| 标注项 | 用途 |
|---|---|
| 左室、右室、左房、右房血池 | 从后端组织掩膜中去掉：血池应当是暗的，谐波下仍有的杂波不能被当成组织 |
| 左室心内膜、心外膜轮廓 | 前端判据的目标区；聚焦判据的目标带 |
| 远端目标点：心房顶（心尖切面）、左室后壁心包（胸骨旁）、降主动脉 | 深度判据：要盖住的最深结构 |
| 二尖瓣环两点 | 运动检查；心尖切面的聚焦参照 |
| 近场杂波区、肺遮挡的回声失落区 | 从 TGC 目标中去掉，不能靠提亮失落区「补平」 |

- 在 BC0 的极坐标数据上标注，换算为毫米坐标，不在截图上标。
- 两名医生，10% 双标并报告一致性。
- **预标注**：心尖四腔、两腔可用公开心脏超声分割数据（如 CAMUS 数据集）训练的模型预标，医生修改；使用前核对数据许可。其他切面前 50 人手工标，再训练本研究自己的预标注模型。

### 12.2 心内膜显示节段数（心脏特有的质量量尺）

由未参与采集的心脏超声医生盲评：对每一帧，数出左室 17 节段模型中**该切面应当可见、且心内膜清晰连续显示**的节段数。

这是颈动脉方案里没有的东西，也是本方案最重要的标注：

- 它是**临床上公认、与本项目标签规则无关**的质量指标。
- 用它**裁决前端标签**：同一比较集里，节段数最多的那一帧就是「临床最优」，可以直接检验物理判据（§13）选的频率、聚焦、深度是否也是医生眼里最好的。
- 用它**评估闭环**（§15）。

工作量控制：对 100 名受试者的心尖四腔与胸骨旁短轴的 F、Z 全部帧评分（约 100 × 2 × 11 = 2200 帧），其余受试者只评 P 帧与 R 帧（约 200 × 7 × 2 = 2800 帧）。

### 12.3 离线成对偏好阅片（动态范围与曝光）

方法同颈动脉方案 §10.3：从舒张末期 R 帧中抽约 600 帧，按 C2 标定的动态范围档位与增益 ±3 dB、TGC 近 / 远场各一档渲染出不同版本，至少 3 名心脏超声医生两两盲选，用 Bradley–Terry 成对比较模型得到每帧的偏好得分与动态范围标签；B 块里真实采到的两档动态范围作为锚点，检验渲染图与真实图在医生眼里是否一致。

心脏与颈动脉的阅片**分开进行、分开建模**：心脏医生通常偏好血池更黑、对比更强的显示，两种偏好不应混成一个。

### 12.4 前端偏好（心脏新增，可选）

前端参数改变 BC0，不能渲染，但同一比较集里的舒张末期帧本身就可以两两比较。对 §12.2 评了节段数的那部分比较集，再做一次成对盲选（例如频率扫描的 5 帧两两比较），与节段数、物理判据三方对照。

## 13. 数据如何变成标签

增益、TGC 与其余参数一样由网络训练，求解器只做教师。

| 参数 | 比较集 / 数据 | 判据 | 要由人体数据标定的量 |
|---|---|---|---|
| 增益 | 每一帧（起点重抽合成） | 教师：组织掩膜（去掉血池、杂波、失落区）内亮度达到目标 | 心肌的目标灰阶：由 R 帧与偏好阅片标定 |
| TGC | 同上 | 教师：按深度补偿 | 深度走势：心肌、心包、肝脏回声强度不同，不能要求各深度一样亮 |
| 动态范围 | 偏好阅片 | Bradley–Terry 得分最高者 | —— |
| 深度 | D 组 | **能盖住远端目标 + 余量的最浅一档** | 余量：由 R 帧中医生的选择分布标定；心尖切面要完整包含心房 |
| 频率 | F 组 | 远端目标处高出噪声底 ≥ 6 dB 的档中，按 C5 分辨率表取最锐的一档；可接受集合与置信度沿用颈动脉做法 | 余量取多深 |
| 聚焦 | Z 组 | 目标带（心内膜所在深度）内侧向斑点宽度（换算为毫米）最小的一档 | —— |

说明：

- **节段数是裁判**：物理判据与节段数最多的帧不一致时，记录下来。不一致集中出现的地方，就是判据需要修改的地方。第一个 50 人复盘时决定前端标签以物理判据为主还是以节段数为主。
- 深度与频率都以远端目标为准，不再读图像最底部——深度只看「盖不盖得住」，频率只看「目标处有没有余量」，颈动脉体模上两轴互相推的问题在规则层面不存在；仍用 `tests/verify_frontend_chain.py` 验证沿标签走能停下。
- 谐波的频率跨度可能很窄（颈动脉预设的谐波只有 4.4–5.7 MHz，1.30 倍），分辨率差异可能落在 3% 并列门槛之内。若 C5 显示心脏谐波各档分辨率几乎并列，频率标签会以「可接受集合」为主，这一轴的训练价值会较小——这是 C 阶段就能知道的事，届时再决定 F 组是否精简。
- 专家设置不直接当标签，理由同颈动脉方案 §11。

## 14. 训练安排

- **链路**：Field II 预训练 → 颈动脉体模 → 颈动脉人体 → 心脏人体。颈动脉人体数据是离心脏最近的谐波数据。
- **前端输出层**按 C0 的档位表重设，其余装入上一步的模型；增益 / TGC 的标准化按心脏数据重新估计。
- `--scalar-norm levels`；每次验证检查增益斜率，≥ 0.5 的轮次不能入选（§4）。
- 分组按受试者；心房颤动、起搏器、人工瓣膜的受试者单独报告。
- **对照实验**：心脏从零训练、只从 Field II 起、从颈动脉人体起，三者比较，判断颈动脉数据对心脏有没有用；再比较「心脏与颈动脉各一个模型」与「一个模型、按预设区分输出层」。
- **仿真（可选，C 阶段后再定）**：现有 MATLAB 生成器仿的是线阵、65 mm。心脏需要相控阵、扇形、到 240 mm 的仿真，而 Field II 只能仿基波。按线阵 36 个体模用了 9.9 天估算，心脏体积大得多，耗时会成倍增加。只有当人体数据的学习曲线在 300 人时仍未饱和，才值得做。

## 15. 人体闭环实测（第二期，50 名测试受试者）

在胸骨旁长轴、心尖四腔、剑突下四腔上：从预设默认出发，每步存舒张末期帧，运行 `tools_suggest_six_param.py`（需先完成本人标定、并已支持扇形几何），操作者按建议调节后再存，直到建议不动或达到 6 步。最终帧与医生 R 帧、预设 P 帧一起：

- 心内膜显示节段数（§12.2）——主要终点；
- 成对偏好比较（胜 / 平 / 负）；
- 帧率、步数、用时。

成像困难者单独报告，这是最能体现闭环价值的人群。

## 18. 风险与未决问题

1. **心电门控与多帧导出不可用**：心脏前端扫描就做不成，本方案退化为只有后端数据与专家帧（增益、TGC、动态范围仍可训练，深度、频率、聚焦只能学专家）。这是第一优先要查清的事。
2. **深部体模**：C4、C5 需要 200 mm 以上的均匀背景与线靶。
3. **谐波频率档可能太少、太窄**，频率这一轴在心脏上的可优化空间可能很小（§13）。
4. **帧相关（时间平均）**：心脏预设通常开着，它让存下的帧是几帧的平均，快速运动的结构（瓣膜）会模糊，舒张末期的定位也会偏；C0 时要确认它对 BC0 是否起作用（它可能在 BC0 之后）。
5. **侧向增益补偿**：心脏临床常用它补侧壁回声失落，本方案关闭它；若医生普遍认为不开侧向增益补偿就调不出满意的图，要考虑把它作为第七个参数，而不是让 TGC 去替它做事。
6. **医生之间的差异**：心脏的主观性高于颈动脉，双人对照量出的差异决定死区与可接受集合能收多紧。
7. **与颈动脉共用一台主机**：两个预设切换频繁时，要确认预设里的固定设置不会被误改（每帧核对）。
