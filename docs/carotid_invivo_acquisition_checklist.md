## 表四　注意事项

| 情况                               | 做法                                                     |
| :--------------------------------- | :------------------------------------------------------- |
| 每次改完参数                       | 先看屏幕上的深度、频率、焦点是否与表中一致，再存图       |
| 深度换到 59、67 毫米时画面底部变黑 | 正常现象，不要调增益                                     |
| 持探头的手                         | 全程不动，只用另一只手操作面板                           |
| 受试者吞咽、咳嗽、说话             | 等平静后，从当前这一组（频率、焦点或深度）的第一帧重新采 |
| 探头明显移动                       | 回到第 1 帧的设置，找回切面后重新采当前这一组            |
| 某一帧档位拨错就存了               | 不删除，在记录表上注明，按正确档位重新存一帧             |
| 第 23 帧的动态范围恰好是 45 或 100 | 第 26、27 帧改为 30 和 150                               |
| 屏幕上出现自动优化或增益自己变化   | 关掉自动优化，重新采本切面                               |
